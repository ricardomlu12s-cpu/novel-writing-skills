# 势力成长(Faction Growth)

家族/公会/宗门/第四天灾玩家群体的成长曲线与状态机。与"个人战力成长"并列的另一条成长线。

## 势力成长曲线
```
起步 → 扩张 → 鼎盛 → 危机 → 转型
(草创/招人) (占地盘/扩资源) (巅峰) (内忧外患) (变革或衰落)
```

## 四维状态机(每势力)
```json
{"id":"f001","name":"青云宗","phase":"扩张",
 "resources":60,"members":120,"prestige":45,"territory":3,
 "crisis":null,"transformed":false}
```
| 维 | 含义 | 变化驱动 |
|----|------|---------|
| **资源** | 灵石/资金/物资 | 经营/掠夺/贸易 |
| **成员** | 人数/质量 | 招揽/损失 |
| **威望** | 名声/威慑 | 战绩/事件 |
| **地盘** | 领地/据点 | 扩张/丢失 |

## 势力成长阶段检查
- 每个阶段有**明确事件**驱动(扩张=新地盘事件,鼎盛=巅峰事件,危机=内忧外患)。
- 势力不会直线上升:鼎盛后必有危机(张弛)。

## 与主角联动(双向)
- **主角借势力**:借资源/人手/靠山(借力打力)。
- **势力借主角**:主角战绩提升势力威望/地盘(反哺)。
- 联动缺失 → 势力与主角脱节(告警)。

## 与战力系统区分
- **势力战力 ≠ 个人战力**:宗门整体强 ≠ 主角强(主角仍是个人成长线)。
- 势力战力影响"环境压强"(主角面对的整体威胁),不替代个人战力。

## 势力类型扩展
- 家族(代际传承,与群像联动)/ 公会(网游)/ 宗门(玄幻)/ 第四天灾玩家群体(异世界召集)。
- 题材知识库(genre-knowledge)按题材提供势力类型模板。

## 与现有衔接
- 设定库(build-world)→ `factions.jsonl` 入设定。
- 群像(ensemble-cast)→ 家族势力与代际群像联动。
- 爽点(plan-plot)→ 势力扩张本身是爽点来源(攻城略地/家族崛起)。
