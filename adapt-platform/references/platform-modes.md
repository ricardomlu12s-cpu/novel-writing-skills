# 平台模式(Platform Modes)

同一本书,起点版和番茄版是**两种完全不同的写法**。开书选平台 → 注入对应写作参数。

## 双平台差异表
| 维度 | 起点模式 | 番茄模式 |
|------|---------|---------|
| 阅读场景 | 深度阅读、长线追更(三五百万字) | 碎片化快读、爽感高频释放 |
| 章节长度 | 2500-3500 字 | 1500-2500 字 |
| 爽点频率 | 每 3-5 章一次 | 每章 1-2 次高频 |
| 伏笔 | 绵延数卷(读者记性好) | 短伏笔,服务前期爽点 |
| 开篇 | 慢热铺垫(黄金三章放宽) | 三章内爆点(黄金一句拉满) |
| 主角人设 | 智力/谋略/大局观/性格成长 | 果断杀伐/高能脑洞/反差感 |
| 世界观 | 战力体系严密、伏笔绵延 | 概念一目了然、设定服务前期爽点 |

## 注入参数(写每章时按平台装配)
```
platform-config.md:
- 章节目标字数: 3000(起点) / 2000(番茄)
- 爽点频率: 每4章1次(起点) / 每章1-2次(番茄)
- 伏笔密度: 长线埋设(起点) / 短线回收(番茄)
- 开篇: 慢热(起点) / 三章爆点(番茄)
- 人设: 智力型(起点) / 杀伐型(番茄)
```

## 质量门按平台校准
- **起点版**:不强制三章爆点(可慢热);要求伏笔绵延/战力严密。
- **番茄版**:必须三章内爆点;要求每章有爽点;世界观概念一目了然。

## 双平台联动(可选)
- 同一世界观,可出起点长线版 + 番茄快读版(双版本策略)。
- 平台切换:改注入参数即可,设定/大纲不动。

## 与现有衔接
- 爽点频率 → satisfaction-cycle(番茄高频/起点低频)。
- 开篇 → golden-three-chapters(番茄硬约束,起点放宽)。
- 金句 → golden-line-gate(番茄高频短金句,起点低频长金句)。
