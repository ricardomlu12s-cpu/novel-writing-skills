# Platform Adapt — 平台适配 + 群像 + 势力

三机制:平台模式(同一本书两种写法)、群像塑造(无绝对主角)、势力成长(家族/公会/宗门)。

## 1. 平台适配(起点 / 番茄)
- 完整差异表见 `references/platform-modes.md`。核心:
  - **起点**:章节 2500-3500 字、爽点每 3-5 章、伏笔绵延数卷、慢热铺垫、智力人设、战力严密。
  - **番茄**:章节 1500-2500 字、爽点每章 1-2 次、短伏笔服务爽点、三章内爆点、果断杀伐/脑洞反差、概念一目了然。
- **开书选平台** → 注入对应写作参数(章节长/爽点频/伏笔密/开篇节奏/人设类型)。
- **质量门按平台校准**:起点版不要求三章爆点;番茄版必须。

## 2. 群像塑造(无绝对主角)
- 完整方案见 `references/ensemble-cast.md`。核心:
  - **无绝对主角**:多主角群像(玄鉴仙族式家族代际 / 赤心巡天式局中局群像)。
  - **多 POV 分配**:各主角独立视角线,轮流推进。
  - **群像弧光**:每主角独立弧线,群像层面咬合(互动驱动剧情)。
  - **代际延续**:家族群像中,一代人的弧光传给下一代。
  - 与 high-state-machine-sync 联动:每主角独立状态机,群像层再咬合。

## 3. 势力成长(家族/公会/宗门/第四天灾)
- 完整方案见 `references/faction-growth.md`。核心:
  - **成长曲线**:起步 → 扩张 → 鼎盛 → 危机 → 转型。
  - **四维状态机**:资源 / 成员 / 威望 / 地盘。
  - **与主角联动**:主角借势力 / 势力借主角(双向)。
  - **势力战力 ≠ 个人战力**(与 power-system 联动)。

## 喂给谁 / handoff
- **write-chapter**:平台参数注入流水线(章节长/爽点频);群像章节多 POV 装配。
- **build-world**:势力状态机入设定库;题材知识库联动。
- **plan-plot**:爽点频率按平台校准;群像弧光调度。
- **write-novel**:平台/群像/势力需求路由到本 skill。
