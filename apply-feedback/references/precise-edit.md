# 精准修改(Precise Edit)

生成章节有不满意的,给意见后**精准定位修改**——不笼统改整章,只改被点到的段落/句子。

## 定位-修改两步法

### 第一步:定位(意见 → 具体位置)
从意见中提取**定位锚**:
- **关键词锚**:意见里的具体词/意象(如"金手指副作用")→ 在章节中 grep 定位。
- **行号锚**:用户说"第X段""最后一段" → 段落定位。
- **语义锚**:意见描述的位置(如"打脸那段")→ 语义定位。

```bash
# 关键词锚定
/usr/bin/grep -n "金手指" <项目目录>/manuscripts/ch087.md
# 段落定位:先看章节结构(空行分隔段落)
```

### 第二步:精准替换
- **只改定位到的段落/句子**,其他段落不动。
- 修改后**校验改动范围**:diff 应只包含目标段落,无意外改动。
- 改后过 remove-ai-tone(去AI味)+ 质量门。

## 精准 vs 整章
| 场景 | 用精准 | 用整章重写 |
|------|--------|-----------|
| 一句/一段不满意 | ✅ | ❌ |
| 本章节奏/结构问题 | ❌ | ✅(走 B/C 分级) |
| 涉及伏笔/战力 | 精准改 + 级联 | 分级评估 |

## 修改记录
- 每次精准修改记入 `apply-feedback-log.md`:意见 → 定位锚 → 改了什么 → 动了哪些段。
- 可回溯:改错了能回看"上次改了什么"。

## 防范围失控
- 修改前**先展示定位到的原文片段** + 拟改内容,确认后才动。
- 用 Edit 精准替换(精确 old_string),不用整文件 Write 覆盖。
