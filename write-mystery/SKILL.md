# Intellect Duel — 智斗引擎

写出**《十日终焉》级别**的智斗:每一步推理都有依据、线索公开程度讲究、知识运用真实且得当、读者回头看完全能复盘。

## 四机制总览
```
【推理链】结论 = 线索(可见的) + 知识(真实的) → 逻辑推出,不跳步
【线索账本】每条线索:状态(隐藏/部分/公开) + seen-by + 公开章节 + 是否伪线索
【知识校验】生/心/社/哲知识库 + "推理用的知识对吗/用得对吗"
【公平竞赛】结尾复盘:关键线索必须公开过或明确隐藏过,防开天眼
```

## 1. 推理链检查(防跳步)
- 每条**推理结论**必须标注:由哪条**线索** + 哪条**知识**推出。
- 三查:线索**可见吗**(主角当时能看到)?知识**真实吗**(推理用的知识必须真实)?逻辑**成立吗**(线索+知识→结论)?
- 跳步(结论无线索支撑/用了主角看不到的信息)→ 告警,补推理链。
- 脚本:`scripts/reasoning_chain_check.py <结论> <线索集> <知识集>`
- 方案见 `references/reasoning-chain.md`。

## 2. 线索账本(线索公开程度)
- 每条线索:状态机 **隐藏 → 部分公开 → 已公开** + seen-by(谁看到)+ 公开章节 + 是否伪线索(撒谎/误导)。
- **公开程度讲究**:关键线索的"部分公开"是最佳设计(读者看到一半,主角利用信息差)。
- 脚本:`scripts/clue_ledger.py`(登记/更新/复盘报告)。
- 方案见 `references/clue-ledger.md`。

## 3. 知识校验(生/心/社/哲)
- 知识库四域(存 `<项目目录>/knowledge-base/`):
  - **生物学**:生理反应/进化心理/神经机制(如"人在说谎时瞳孔放大/语速变化")。
  - **心理学**:认知偏差(确认偏误/锚定)/博弈/动机(如"越心虚越强调清白"=防御机制)。
  - **社会学**:群体/权力/制度/阶层(如"规则由谁制定、谁受益")。
  - **哲学**:伦理/逻辑/存在(如"电车难题式抉择"的哲学依据)。
- 角色推理/行为用的知识:**真实吗**(知识库校验)+ **用得对吗**(符合情境/人物设定)。
- 人物刻画也按理论基础(性格=心理学驱动,行为自洽)。
- 方案见 `references/knowledge-verification.md`。

## 4. 公平竞赛检查(可复盘)
- 结尾复盘:所有**关键线索**必须**公开过**(或明确隐藏过,且隐藏本身有交代)。
- 主角开天眼/作者硬推 → 告警。
- 读者回头看:每条结论都能从已公开线索推出(推理链完整)。
- 方案见 `references/fair-play-check.md`。
