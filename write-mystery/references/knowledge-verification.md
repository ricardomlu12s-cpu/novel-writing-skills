# 知识校验(Knowledge Verification)

角色的推理、行为、人物刻画都要有**真实且用得对**的理论基础(生物/心理/社会/哲学)。防"伪智斗"(用了错知识)和"标签化人物"(无理论驱动的性格)。

## 知识库四域(存 `<项目目录>/knowledge-base/`)
| 域 | 文件 | 内容 | 智斗用法例 |
|----|------|------|------------|
| **生物学** | bio.md | 生理反应/进化心理/神经机制 | "说谎时瞳孔放大、语速微变"→ 测谎推理 |
| **心理学** | psych.md | 认知偏差/防御机制/动机/博弈 | "越强调清白越心虚"(防御机制)→ 识破 |
| **社会学** | socio.md | 群体/权力/制度/阶层 | "规则由谁制定、谁受益"→ 破解规则 |
| **哲学** | phil.md | 伦理/逻辑/存在 | 电车难题式抉择的哲学依据 → 角色抉择 |

## 校验两条(推理/行为用知识必过)
1. **真实吗**:知识本身是否正确(与公认科学/理论一致)。
   - 错例:说"肾上腺素会让人冷静"(实际是兴奋)。
   - 对例:杏仁核负责恐惧反应 → 恐惧推理。
2. **用得对吗**:符合情境 + 符合人物设定。
   - 角色是医生 → 可用医学生物知识;是村汉 → 用了心理学术语就违和。
   - 知识应用符合人物知识边界(POV 知识边界联动)。

## 人物刻画理论基础(防标签化)
- 性格不是形容词,是**理论驱动的行为模式**:
  - "偏执" → 心理学"确认偏误"(只找支持自己判断的证据)→ 行为自洽。
  - "隐忍" → 心理学"延迟满足"+"高自我监控" → 行为自洽。
  - "冷漠" → 心理学"回避型依恋"或创伤防御 → 行为自洽。
- 每角色卡标"理论驱动":性格 ← 什么心理/社会机制 → 什么行为。
- 与 psychodynamic-char(动机-恐惧矩阵)联动:矩阵给"为什么",理论给"行为怎么自洽"。

## 知识库维护
- 随用随补:新知识 → 追加到对应域文件(标注来源/领域)。
- 校验时:查知识库 → 不在库 → 需人工/LLM 确认真实后入库存。
- 防伪知识:知识库只收录真实/公认知识;虚构设定(玄幻战力)走 power-system,不混入。

## 集成
- 智斗推理:knowledge-verification 校验推理用知识(推理链的第 2 查)。
- 人物刻画:角色卡写"理论驱动",质量门校验行为自洽。
