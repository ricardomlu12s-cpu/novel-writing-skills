# 推理链检查(Reasoning Chain)

每条推理结论必须"由可见线索 + 真实知识 → 逻辑推出"。防跳步、防开天眼。

## 推理链结构
```
结论 ← 线索(主角当时可见的) + 知识(真实的) → 逻辑推演
```

## 三查(每条推理结论必过)
| 查 | 问 | 不过 |
|----|-----|------|
| **线索可见** | 主角当时能看到这条线索吗?(公开/部分公开且主角在场) | 用隐藏线索 = 开天眼 |
| **知识真实** | 推理用的知识真实吗?(生/心/社/哲校验) | 用错知识 = 伪智斗 |
| **逻辑成立** | 线索+知识 → 结论,逻辑闭合吗? | 跳步 = 硬推 |

## 跳步检测
- **结论无线索支撑**:主角直接"猜到"→ 断链告警。
- **用了主角看不到的信息**:作者视角泄漏 → 断链告警。
- **用了错误知识**:推理依据本身错 → 断链告警。
- **逻辑不闭合**:线索→结论有跳跃 → 断链告警。

## 推理链标注格式(写作时)
```
结论: 凶手是管家
链条: 线索[第3章:管家袖口的血渍(部分公开,主角看到)] 
      + 知识[血迹干涸时间与案发时间吻合(法医学)]
      → 结论[管家在案发时间在场且受伤]
```
每章推理场景都标链条;质量门检查链条完整。

## 与公平竞赛衔接
- 推理链完整 = 公平竞赛的前提(读者能复盘)。
- 推理链断链 = 要么补链,要么改线索可见性。
