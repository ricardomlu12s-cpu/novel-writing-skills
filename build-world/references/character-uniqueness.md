# 角色独特性(Character Uniqueness)

四维卡保证角色"立体、说话不同",但两个"隐忍复仇型"会长一样。本机制强制每个角色有**不可替代的独特内核**。

## 独特内核(角色独有,不可复制)
| 内核 | 含义 | 例 |
|------|------|-----|
| **专属金手指形态** | 金手指的形态/来源独特(非通用"系统") | 金手指是"一本会吃字的书"而非通用系统面板 |
| **独特信念** | 信念非通用("变强/复仇"),而是个人化 | "我要让所有被当作棋子的活成棋手" |
| **独有说话方式** | 声线库之上的"专属语言指纹" | 某个角色说话必带"因果报应"式偈语 |
| **专属怪癖/道具** | 独有癖好/随身物(承载情感) | 杀手随身带着一朵不会谢的纸花 |
| **独特缺陷** | 非通用"莽撞",而是结构性缺陷 | 记忆错乱,把过去和幻境混淆 |

## 互换测试(核心)
**把两个角色的卡互换,故事还成立吗?**
- 能互换 = 无独特性 → 告警(角色可替换,读者无记忆点)。
- 不能互换 = 有独特内核(该角色不可替代)。

## 检查清单(每角色)
1. 有专属金手指形态吗?(非通用"系统")
2. 信念个人化吗?(非"变强/复仇"通用)
3. 说话方式独一无二吗?(去掉标识能认出)
4. 有专属怪癖/道具吗?(承载情感记忆点)
5. 有独特缺陷吗?(结构性,非通用莽撞)
6. 互换测试:换掉这个角色,故事还成立吗?(成立=无独特)

## 与现有衔接
- 四维卡(显性目标/隐性需求)→ 独特性在此基础上加"专属形态"。
- 声线库 → 独特性加"专属语言指纹"(说话必带的标志)。
- 团队查新(novel-team-composition)→ 个体独特+组合新奇。
