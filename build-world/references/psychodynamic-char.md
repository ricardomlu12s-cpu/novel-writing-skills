# 角色灵魂建模(Psychodynamic Characterization)

把角色从"形容词标签(Static Tags)"升级为"动机-恐惧矩阵(Motivation-Fear Matrix)"。防"纸片人"与"设定说明书"。

## 核心:动机-恐惧矩阵
| 层 | 定义 | 例 |
|----|------|-----|
| **公开目标** | 角色向外展示的追求(伪装/短期) | 想当上少宗主 |
| **隐藏欲望** | 灵魂真正缺的(需故事历程补完) | 渴望被认可、被父亲看见 |
| **错误信念(The Lie)** | 角色深信但错误的信条(驱动其行为) | "强大就必须冷漠" |
| **形成性创伤** | 过去阴影(错误信念的来源) | 儿时软弱害死至亲,被骂"没用" |

**冲突来源**:公开目标 ↔ 隐藏欲望 打架(想当少宗主只是手段,真需求是被看见)。错误信念扭曲了实现方式(以为冷漠才强大,实际推开所有人)。

## 行动化呈现(Show, Don't Tell)—— 强制检查
- **禁**:形容词标签("他很冷漠""她很坚强")。
- **必**:行动/生理/微动作呈现 → 读者自行得出。
  - ~~他很冷漠~~ → 他掐灭了递来的火盆,没看对方。
  - ~~她假装坚强~~ → 她咽下喉咙的腥甜,笑着把药碗推回去。
- 每章角色出场时,检查是否有**行为证据**支撑其矩阵;只有标签没有行动 → 打回。

## 防"设定说明书"
- 角色信息不能一次性堆给读者(简历式)。通过**场景中的行动与抉择**逐层揭示。
- 四维卡的"创伤心结"是**隐藏的**,不是旁白说出来,而是通过回避话题/反常行为透露(呼应声线库的"回避")。

## 与现有资产衔接
- 四维卡(显性目标/隐性需求/创伤心结/言语防线)= 矩阵的浅层版本;本机制补上**错误信念 + 冲突来源 + 行动化检查**。
- 声线库(voice-lines)用"回避话题"体现创伤。
- 成长弧线 = 错误信念被打破的过程(角色弧光的本质)。

## 检查清单(每章角色出场)
1. 该角色有动机-恐惧矩阵吗?(不是形容词)
2. 行为是否支撑矩阵?(有证据,非标签)
3. 公开目标与隐藏欲望是否冲突?(有内部矛盾)
4. 有无"设定说明书"式堆砌?(有 → 拆到场景中)
