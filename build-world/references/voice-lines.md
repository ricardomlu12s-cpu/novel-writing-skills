# 角色声线库(防说话均质化)

每个核心角色必须有**独立的词汇库 + 句式偏好**,脱离说话人标识,读者依然能通过文本特征识别是谁在说话。

## 声线四维
| 维度 | 内容 | 例 |
|------|------|-----|
| **口头禅/口头语** | 高频插入语 | "罢了""有趣""我辈当如此" |
| **句式偏好** | 长句/短句、反问/设问 | 谋士多用反问,武夫多用短句 |
| **词汇域** | 用词范围(市井/文雅/军旅/黑话) | 江湖人用切口,贵族用雅言 |
| **回避话题** | 刻意回避的词/话题(与创伤心结联动) | 失孤者回避"家""娘" |

## 声线卡模板(角色卡内)
```markdown
## 声线
- 口头禅: <如 "有趣">
- 句式: <短句为主,常自问自答>
- 词汇域: <市井俗语>
- 回避: <"家"、提及母亲>
```

## 防均质化检测
- 同一场景多角色对白,若去掉"某某说"后无法区分说话者 → 声线失败,需重写。
- 角色口头禅若在每章对白中 <1 次 → 可强化;若 >3 次 → 过度,稀释其效果。

## 与 learn-style 衔接
- learn-style 的文风指纹是"全书的文风";声线库是"每个角色的文风",二者是整体与个体关系。

## 与四维卡联动
- 声线的"回避话题"来自四维卡的**创伤心结**(隐性需求的反面)。
