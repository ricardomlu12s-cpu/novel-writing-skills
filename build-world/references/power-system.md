# 战力系统(Power System)

防"战力崩坏"的设定与校验。核心理念:**战力要有等级框架、平衡约束、成长曲线**,并接受校验。

## 1. 战力等级框架
```
power-system.md (存于 <项目目录>/):
# 战力系统
## 等级划分
- L1 凡体 < L2 炼体 < L3 凝气 < L4 筑基 < L5 金丹 ...(题材自定)
## 每级能力边界
- L3:可徒手碎石,不能飞行
- L5:可御剑,不能撕裂空间
## 克制关系 / 平衡
- 同级 1v1 势均力敌;越级挑战必须有代价(爆种/秘法/燃烧寿命)
## 成长曲线
- 正常:1级/卷(约30章);奇遇:快 2 级但留副作用
```

## 2. 角色卡加战力字段
每个角色卡加:
```markdown
## 战力
- 等级: L4 筑基
- 战力值: 120(同级参考 100)
- 成长曲线: 卷1 L2→L3, 卷2 L3→L4
- 越级记录: 无(或 1 次,有代价)
```

## 3. 战力校验(防崩坏,确定性优先)
- **跳级检测**:单卷等级跳跃 > 2 级 → 告警(除非有奇遇+副作用登记)。
- **越级合理性**:越级挑战成功须有代价(爆种/秘法/牺牲),否则战力失衡。
- **同级平衡**:同级角色战力值差 > 30% → 告警(除非有设定解释)。
- **成长曲线**:等级与章节进度匹配(1级/卷),过快/过慢都告警。

## 4. 与 plan-plot / write-chapter 衔接
- 战力校验进 write-chapter 质量门(战力崩坏 → 打回)。
- 战力状态进创作数据面板(render_panel 战力区)。

## 5. 力量必须有代价 + 能力未知原则(通用)

**血统/力量不是等级**:血统/特殊体质不能简单等同 LV1-LV100。多维记录:
- 潜力 / 评级 / 稳定度 / 身体强化 / 感知 / 恢复 / 精神抗性 / 言灵适应 / 失控风险 / 人格侵蚀风险。
- "学院评级"只是社会对人物的评估,不是绝对战斗力。

**代价铁律**:越接近力量顶点,代价越大——稳定度下降、精神压力上升、人格变化、本能增强、失控风险、组织关注提高。**禁止"高血统/强力量只有好处没有代价"。**

**能力未知原则(Mechanism Unknown)**:某个原著能力/体系若只表现过部分效果、机制有争议、版本有差异,**不要自行补全为绝对规则**。标记"机制未知",通过剧情继续探索(留白也是悬念)。

**反作弊黑名单(力量侧)**:
- 禁止:无限暂停时间 / 绝对无敌 / 无限复活 / 无条件控制任何人 / 无代价复制全部能力 / 无限成长。
- 原创能力/体系必须符合作品世界整体风格(过守恒三问,挂剧情线,不炫设)。

## 6. 暴露度联动
- 主角力量/血统越异常 → 暴露度越高(见 build-world/references/information-truth-layer.md §4)。**不能开局拥有异常力量却永远没人调查。**
