# 团队配置查新(Novel Team Composition)

**团队配置老套雷同**是男频大忌:主角(身世惨/天赋异禀)+ 热血兄弟 + 红颜知己 + 老谋师傅 + 阴险反派 = 几十年老配方。本机制强制团队组合"有新奇化学反应"。

## 常见模板团(命中即查新)
| 模板团 | 配置 | 反例 |
|--------|------|------|
| **热血兄弟团** | 主角+两个好兄弟(一个莽/一个智) | 老三样,无新意 |
| **复仇者联盟** | 主角+被灭门的同伴+复仇导师 | 全员同目标,无张力 |
| **天才少年团** | 天才主角+天才同伴+天才对手 | 全员天才=无衬托 |
| **老带新团** | 主角+世外高人师傅+慈祥师叔 | 师徒模板化 |

## 查新检查(团队组合的"化学反应")
1. **成员类型新鲜吗**:不是模板式(热血兄弟/红颜/师傅)。
2. **关系动力新鲜吗**:成员间关系不是"忠诚跟随",而是有张力(宿敌入队/利益绑定/互不信任)。
3. **互补有新意吗**:成员互补不是"一个莽一个智",而是**意想不到的互补**(如"杀手+会计+说书人")。
4. **团队有矛盾吗**:无矛盾=乌托邦团(不真实),有内部冲突=张力源。

## 打破模板建议
- **换成员类型**:宿敌入队 / 反派当队友 / 非人队友(灵兽/器灵/AI)。
- **换关系动力**:利益绑定的假团队(表面合作,各有目的)/ 师徒反转(徒弟比师傅强)。
- **换冲突源**:团队内部理念冲突 / 成员的秘密互相掣肘。
- **换结构**:无固定团队(独狼+临时搭伙)/ 团队从敌对拼凑。

## 与角色独特性联动
- 团队查新看"组合",角色独特性看"个体"。两者配合:个体独特 + 组合新奇 = 团队立住。

## 检查清单(开书建团队)
- [ ] 成员类型新鲜吗?(非模板式)
- [ ] 关系动力有张力吗?(非忠诚跟随)
- [ ] 互补有新意吗?(非"一个莽一个智")
- [ ] 团队有内部矛盾吗?(有=张力源)
- [ ] 打破模板了吗?(换类型/换关系/换冲突)
