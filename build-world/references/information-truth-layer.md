# 隐藏真相层 + 信息溯源 + 秘密状态机 + 暴露度(Information Truth Layer)

**问题**:创作中最大的"全知视角污染"——作者知道真相,就忍不住让角色也知道、让旁白提前泄露。缺三样东西:①角色"以为的"与"真实"分层;②信息的来源与可信度;③秘密怎么泄露、主角变强后世界怎么反应。

> 通用机制(原创/同人都用)。同人特例:源作的"隐藏真相"由拆书产出(secrets.jsonl),同人正文不得让角色提前知道未揭示的源作秘密。

## 1. 隐藏真相层(角色"以为" ≠ 世界"真实")

把每条关键信息分两层:
- **世界真实**:作者知道的真相。
- **角色认知**:每个角色"以为"的版本(可能对、可能错、可能是被骗的)。

**信息隔离**:角色只能根据「亲眼看到/亲耳听到/可靠资料/别人告诉/合理推断」做判断。维护每个角色对每条关键信息的认知状态:

| 认知状态 | 含义 |
|---|---|
| KNOWN | 确切知道 |
| BELIEVED | 相信(但未必真) |
| SUSPECTED | 怀疑 |
| RUMOR | 听说/传闻 |
| UNKNOWN | 完全不知道 |
| FALSE | 持有错误认知 |

**铁律**:
- 一个角色的秘密**不会自动同步到所有人物脑中**。
- "NPC 说过" ≠ "世界真相"——角色可能在撒谎、被误导、或自己也信了错误信息。

## 2. 信息溯源(Information Provenance)

每条重要信息记录来源与可信度,**禁止无源信息**:

```
信息: <内容>
来源: <谁说的/哪个档案/哪次观察>
可信度: 高/中/低
证据: <实物/证词/线索>
传播链: <A 告诉 B → B 告诉 C>
是否被篡改: <是/否>
```

**核心原则**:真相不能靠单一来源获得。重大秘密需**多个相互独立的证据**。一个 NPC 一句话不能解决整个谜团。

**关键区分**(四态):
- 获得正确结论
- 获得错误结论
- 只发现部分真相
- 发现真相但无法证明

> **"知道真相"和"拥有能让人相信的证据"是两个不同状态**——角色可能知道真相但拿不出证据,别人不会信。

## 3. 秘密状态机(Secret Ledger)

所有核心秘密进入账本,追踪其泄露生命周期:

| 状态 | 含义 |
|---|---|
| HIDDEN | 完全隐藏 |
| LEAKING | 正在泄露(有人开始接近真相) |
| SUSPECTED | 被怀疑 |
| PARTIAL | 部分暴露(知情人部分了解) |
| EXPOSED | 完全公开 |
| DESTROYED | 秘密失效(相关人或物消失) |

**铁律**:秘密公开以后,世界必须记住——不能"已经暴露的秘密重新成为秘密"(除非有新的掩盖 + 因果解释)。

## 4. 暴露度 / 怀疑度(主角变强,世界会反应)

**问题**:主角开局拥有异常力量/血统/能力,世界却永远不调查——这是"主角光环"的核心漏洞。补两套追踪:

**暴露度**(主角整体暴露程度):
| 级 | 含义 |
|---|---|
| EX0 | 无人注意 |
| EX1 | 局部注意 |
| EX2 | 学院/地方组织关注 |
| EX3 | 核心部门关注 |
| EX4 | 多个重要势力调查 |
| EX5 | 世界级异常目标 |

异常能力/公开破坏任务/泄露秘密/改变大事件 → 暴露度上升。**主角不能开局有异常力量却永远没人查。**

**怀疑度**(按组织分别记,不是统一数值):
```
学院: 低
执行部: 中
某势力: 高
```
- 不同组织对主角的态度**可以同时不同**(见 relationship-web「组织不是铁板一块」)。
- 已存在的证据不会凭空消失;解释/掩盖/第三方担保只能改变"态度",不能抹掉"证据"。

## 5. 与现有机制的接缝(不重复)

| 已有 | 本机制补什么 |
|---|---|
| POV 知识边界(pov-boundary.jsonl) | POV 管"谁知道什么秘密";本机制补"角色以为 vs 世界真实"的**分层** + 秘密**泄露状态机** |
| secrets.jsonl(拆书 L3) | 拆书产出"源作隐藏信息";本机制是**写作期**的通用追踪(含原创) |
| write-mystery 线索账本 | 智斗线索是"证据链";本机制是"信息可信度 + 秘密泄露",二者互补 |
| plan-plot 反套路(穿越者知道原著≠NPC相信) | 已是特例;本机制把它泛化为通用"角色认知 vs 世界真实" |

## 6. 检查清单(每章/关键信息点)

- [ ] 这条信息,角色"以为的"和"世界真实"一致吗?(不一致才是悬念)
- [ ] 角色是怎么知道的?(亲眼/亲耳/资料/转述/推断)——无来源 = 全知污染
- [ ] 信息有来源 + 可信度吗?(NPC 说过 ≠ 真相)
- [ ] 重大秘密有多源证据吗?(单一来源不成立)
- [ ] "知道真相"和"能让人信"区分了吗?
- [ ] 主角变强/异常,暴露度升了吗?有组织在查吗?
