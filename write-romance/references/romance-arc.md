# 感情弧光状态机(Romance Arc)

感情发展不是一步到位,是**渐进**的(好感→喜欢→爱→非常爱,有征兆铺陈)。每阶段有**行为证据**(非直说)。

## 弧光状态机
```
吸引 → 试探 → 信任 → 考验 → 确立 → (危机 / 升华)
```

| 阶段 | 行为证据(非直说) | 神作实证 |
|------|-----------------|---------|
| **吸引** | 目光追随/无意识靠近/记住细节 | 记住她咬瓜子壳的笨拙 |
| **试探** | 找借口接近/试探对方反应/隐晦暗示 | 潜台词对话(subtext-dialogue) |
| **信任** | 暴露脆弱/分享秘密/依赖 | 叶芷:深夜偷偷倒尿壶(暗线信任) |
| **考验** | 外部压力/误会/生死抉择 | 米高断腿/普吉岛搜救 |
| **确立** | 明确承诺/双向奔赴 | 思思:一生只等一个人 |
| **危机/升华** | 感情受挫(外部或内部)/或升华为更深的羁绊 | 夏弥之死(必然悲剧)→ 升华 |

## 渐进征兆(防"突然在一起")
- 好感→喜欢→爱,一定有征兆:突然莫名思念、对方生病时开始担心、无意识替对方着想。
- 每阶段铺垫足够(读者跟着一起付出感情),不突然在一起。

## 阶段性蜕变(互动模式演进)
神作范本(捡到个仙子):防御性被动 → 策略性配合 → 主动主导,每阶段有据可依。
- 互动匹配认知进度:初期握手全身戒备 → 中期坦然拥抱 → 后期主动要求"背我"。
- 身体语言变化 = 心理防线瓦解程度(生物+心理)。

## 悲剧要必然(防为虐而虐)
- **必然悲剧**(有因果,处理得当):龙二夏弥——悲剧是性格/命运必然。
- **偶然悲剧**(为虐而虐,被批):绘梨衣——偶然死亡,读者归咎作者。
- 规则:悲剧必须有因果链(角色选择/命运必然),不是"突然死了"。

## 检查清单
- [ ] 弧光在哪个阶段?(有状态机)
- [ ] 阶段有行为证据吗?(非直说)
- [ ] 渐进征兆铺够了吗?(不突然在一起)
- [ ] 互动模式有阶段性蜕变吗?
- [ ] 悲剧有因果吗?(非为虐而虐)
