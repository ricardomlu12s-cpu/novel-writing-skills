# 明暗线机制(Light-Dark Lines)

感情线可分**明线/暗线/对照**,对比出深度(风花雪月式:思思=明线炽烈,叶芷=暗线隐忍)。

## 三模式
| 模式 | 含义 | 神作实证 |
|------|------|---------|
| **明线** | 爱炽烈直白、不计回报,读者直接看到 | 风花雪月:思思(为陪吃早餐从上海飞大理) |
| **暗线** | 爱隐忍付出,埋进细节,读者拼线索 | 风花雪月:叶芷(深夜偷偷倒尿壶/机场回头五次) |
| **对照** | 明暗两线对比,深度互衬 | 思思如火 × 叶芷如水 |

## 暗线设计(第一人称视角拼线索)
- **第一人称叙事**:读者只能看到主角视角,暗线的付出需读者自行推敲。
- 暗线线索:细节动作(深夜倒尿壶)/ 物品(床单厂女人/B超单)/ 明信片暗示。
- **信息差**:主角误解暗线方的付出(恨她不守承诺)→ 真相揭开反转(她从未结婚,孩子是他的)。
- 效果:既塑造暗线方形象,又增加可读性与解读空间。

## 明线设计
- 明线直接呈现:炽烈行为(陪吃早餐/深夜飞回过年/四百万创业资金)。
- 读者直接共情(明线方往往是"意难平")。

## 对照效果
- 明暗对照:火 vs 水、直白 vs 隐忍 → 深度互衬。
- 读者站队(思思党 vs 叶子党)→ 讨论度/传播度。

## 与现有衔接
- 暗线 = 感情版的"伏笔"(线索埋设,后期回收)。
- 与 write-mystery 线索账本联动:暗线付出 = 线索,读者拼线索 = 智斗式阅读。
- 与 POV(群像 ensemble-cast)联动:第一人称视角的暗线设计。

## 检查清单
- [ ] 感情线是明线/暗线/对照?(选定了模式)
- [ ] 暗线:付出埋进细节了吗?读者能拼出线索吗?
- [ ] 暗线有信息差/反转吗?(主角误解 → 真相揭开)
- [ ] 对照:明暗对比出深度了吗?
