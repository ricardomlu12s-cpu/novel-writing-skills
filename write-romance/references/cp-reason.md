# CP 合理性校验(CP Reason)

为什么这两个人相爱?——这是真实感情线的第一问。无依据 = 工业糖精。

## 三大合理性来源(至少其一,最好叠加)
| 来源 | 含义 | 神作实证 |
|------|------|---------|
| **个性吸引** | 对方身上有"你缺/你向往"的特质 | 捡到个仙子:记住她咬瓜子壳的笨拙(非"仙子"标签)——吸引=具体个性 |
| **创伤共鸣** | 相似创伤/缺失,互相看见彼此 | 龙族:路明非缺爱,诺诺是第一道光(但单向执念=反面) |
| **经历绑定** | 共同经历(生死/共患难/日常积累) | 风花雪月:米高×思思=日常+危机积累 |

## 校验三问
1. **为什么是他/她**:换一个人行不行?换谁都行 = CP 无理由(工业糖精)。
2. **吸引的是个性不是标签**:是"她咬瓜子壳的笨拙"不是"她是仙子"(标签化=虚假)。
3. **经历是"积累"不是"一次"**:一次英雄救美不够,要日常积累+危机催化。

## 反向:爱有理由,不爱也有理由
- 角色的"不爱"同样要合理(米高最初不接受思思:年龄差/不成熟/差距大)。
- CP 被拒要有现实理由(社会学:阶层/身份/环境),不是"作者不让"。

## 检查清单
- [ ] 为什么相爱?(个性/创伤/经历,至少其一)
- [ ] 换个人行吗?(不行 = CP 成立)
- [ ] 吸引的是个性不是标签?
- [ ] 经历是积累不是一次?
- [ ] 不爱/被拒也有理由?
