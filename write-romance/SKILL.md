# Romance Engine — 感情线引擎

写出**真实感情线**(符合情节/角色,生/心/社/哲理论基础,不工业糖精)。以《龙族》《我在风花雪月里等你》《捡到个仙子怎么办》等神作为对照(正面+反面案例已查证)。

## 七机制
1. **CP 合理性**:为什么这两个人相爱?(个性吸引/创伤共鸣/经历绑定)→ 无依据=工业糖精。见 `references/cp-reason.md`。
2. **感情弧光**:吸引→试探→信任→考验→确立→(危机/升华),每阶段**行为证据**(渐进征兆,非直说)。见 `references/romance-arc.md`。
3. **明暗线**:可选明线(炽烈直白)/暗线(隐忍付出,第一人称拼线索)/对照(风花雪月式)。见 `references/light-dark-lines.md`。
4. **双向奔赴**:无系统绑定/无单向拯救,日常积累+性格张力+危机催化自然生成。
5. **承载功能**:感情戏=世界观碰撞+人物成长+主题深化(非甜宠点缀)。
6. **理论基础**:心理学(依恋/爱情三角/渐进)+ 社会学(阶层/身份/环境)+ 生物学(吸引力)+ 哲学(爱作为主题)。见 `references/theory-basis.md`。
7. **雷点检测**:禁一见钟情即定终身/无铺垫突转/为虐而虐/工具化/无成长/幼稚表达。见 `references/red-flags.md`。

## 神作对照(核心认知)
- **该做**:明暗线对照(风花雪月思思/叶芷)、爱有理由(个性吸引)、渐进征兆、双向奔赴、阶段性蜕变、悲剧要必然(龙二夏弥)、感情承载功能。
- **别做**:一见钟情即定终身、铺垫不足突转(雪中陆丞燕)、为虐而虐(绘梨衣)、女性工具化、感情线无成长(龙四)、表达幼稚。

## 理论基础贯穿
- 每个阶段、每次感情决策,按生/心/社/哲校验(行为自洽,非标签)。
- 人物刻画:性格 ← 心理机制(依恋/防御)→ 行为(自洽)。

## 集成进质量门
- 感情戏章节 → write-chapter 质量门调用七机制(CP合理性/弧光阶段/雷点)。
- 与角色卡(psychodynamic-char)/关系网(relationships.jsonl)/群像(ensemble-cast)联动。

## 喂给谁 / handoff
- **write-chapter**:感情戏章节质量门调用七机制。
- **build-world**:CP 关系入 relationships.jsonl;角色卡补"感情相关创伤/依恋类型"。
- **adapt-platform**:起点(慢热感情线)vs 番茄(快节奏感情线)按平台校准。
- **write-novel**:感情线需求路由到本 skill。
