# 定稿强制检查清单(Final Check List)

**防跳步**:9 步流水线靠模型自觉执行是软约束。本清单让每章定稿前**逐项强制打勾**,任何一项未过 → 不得进定稿。

## 定稿前逐项打勾(9 项,缺一不可)

| # | 检查项 | 依据 | 过/不过 |
|---|--------|------|---------|
| 1 | **记忆同步** | 本章装配了活跃实体(角色卡/伏笔/摘要)吗? | ☐ |
| 2 | **一致性** | 与正典账本无矛盾(连续性 11 项确定性检查) | ☐ |
| 3 | **RAG 回读** | 关键节点(伏笔回收/转折)回读原文了吗? | ☐ |
| 4 | **硬约束** | 战斗/关键场景注入世界观硬约束了吗? | ☐ |
| 5 | **风格校准** | 对照风格指纹,风格一致吗? | ☐ |
| 6 | **衔接检查** | 该兑现伏笔/该出现角色戏份/蝴蝶下游查了吗? | ☐ |
| 7 | **去AI味** | detect_aislop + 非人感扫描过了吗? | ☐ |
| 7.5 | **机器化检测** | machinese_detect(词汇重复/句式单调/转场/模板/表层情绪)命中 <2 项了吗? | ☐ |
| 8 | **标点规范** | normalize_punct 过了吗 + check_punct_spec(引号平衡/嵌套/漏配)过了吗? | ☐ |
| 9 | **软质量** | AI 给了章节位置+结构建议,你裁决了吗? | ☐ |

## 执行规则
- **逐项打勾**:每章定稿前,逐项确认,不能口头"应该没问题"。
- **未过项处理**:未过 → 打回对应环节,补完再回来。
- **跳步零容忍**:任何一项跳过 = 不算定稿(宁慢勿糙)。

## 与流水线衔接
- 流水线(第 1-9 步)是执行,本清单是**定稿前验收**。
- 清单在 manuscripts/ 定稿前必跑,结果可记入 lessons 或 panel。

## 目的
- **防跳步**(模型图省事跳过某步)。
- **防"假通过"**(嘴上说过,实际没查)。
- 让"每章检验"从**靠自觉**变**强制清单**。
