# 分卷/分会话生成规划(Volume-Session Plan)

超长篇(1500 章级)的工程化分配:**划分边界 = 剧情节点,不是平均数字**。分卷按弧线收束切,分会话按 token 阈值 + 剧情断点双条件切(断点优先)。

## 核心原则:剧情驱动,不平均
| 划分 | 边界依据 | 反例(生硬) |
|------|---------|------------|
| **卷** | 剧情弧**收束处**(伏笔兑现/高潮落幕/关系重大转折) | 固定 70-100 章一刀切 |
| **会话** | token 阈值到 + **剧情断点**双条件,断点优先 | 固定 10-20 章硬切 |
| **区块** | 事件/场景完成(一场战斗/一次推理) | 固定 5 章机械切 |

## 三层切割(剧情驱动版)
```
全书 1500 章
  → 卷 按弧线:短弧~40章/卷,长弧~120章/卷,以弧收束为界(15-25 卷)
  → 会话段 每 10-20 章(token 阈值)但避开剧情中段,在高潮则续写到弧收束
  → 区块 按事件完成,非固定章数
```

## 分卷边界(叙事节点)—— 只在这些点切卷
- ✅ 一个剧情弧**收束处**(伏笔兑现 / 高潮落幕 / 悬念揭晓)。
- ✅ **换地图**/换势力(旧地图危机清理,新地图引出)。
- ✅ 角色关系**重大转折后**(结盟/决裂/蜕变)。
- ✅ 卷末必有**新钩子**引下卷。
- ❌ 绝不在大战/悬念正中间切卷。

## 分会话边界(token 阈值 + 断点双条件)
1. **token 阈值**:累计 >70% 或写满 ~10-20 章(经验值)。
2. **断点检查**:阈值到后,先看当前剧情位置:
   - 在**铺垫/过渡** → 可在本段末尾切。
   - 在**爆发/高潮** → **多写几章到弧收束再切**,不硬切。
   - 在**伏笔回收中** → 回收完成再切。
3. **落盘断点**:checkpoint.md 记"下章目标",新会话无缝续。

## 怎么判断断点位置
- **plan-plot 高潮调度**:当前张力值(铺垫1-3/发酵4-6/爆发7-10/收束2-3)。
- **伏笔状态机**:悬置 vs 回收中。
- **关系状态机**:重大转折发生没。
- 只在**收束期/卷末**切,不在**爆发期**切。

## 每会话节奏(剧情驱动)
```
1. 说"续写《书名》" → 自动装配(L5+L4+L3+L2 + 账本 + lessons + checkpoint)
2. 连续写章(每章质量门 + 去AI味 + 飞轮沉淀)
3. 每到一个剧情断点:刷新面板
4. token 阈值到 + 正好在断点 → 落盘 checkpoint → 结束会话
5. 若阈值到但在高潮 → 续写到弧收束再切
```

## 各章规模
| 题材 | 每章字数 | 会话段经验值 |
|------|---------|-------------|
| 网文(玄幻/都市) | 2000-3000 字 | 15-20 章(断点调整) |
| 严肃向/精修 | 3000-5000 字 | 10-15 章 |
| 快节奏短平快 | 1500-2000 字 | 15-20 章 |

## 与 token 预算守卫衔接
- 预算守卫在 token 阈值触发"是否开新会话";配合本规划的"断点优先",不硬切。

## 防 token 膨胀
- 每章注入恒定(L5+L4+L3+L2 + 活跃实体 + RAG + lessons),不随总章数涨。
- 会话级累积靠"token 阈值 + 断点优先 + checkpoint"控制。
