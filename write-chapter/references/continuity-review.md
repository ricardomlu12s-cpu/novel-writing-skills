# 章节衔接检查报告(Continuity Review)

**对未来的构想与衔接**不能只停留在设计层(伏笔账本/命运账本),写每章时必须**实时查"该兑现什么"**。本机制让衔接从"靠人记得"变"每章自动提醒"。

## 定位(诚实)
- **可量化的衔接** → 严格查(伏笔/命运/蝴蝶/承诺)。
- **不可量化的节奏** → 交给人(见 quality-division.md)。
- 本报告是**提醒/参考**,不是自动改稿;最终是否"现在写"由作者裁决。

## 每章写完自动生成"衔接检查报告"

### 1. 该兑现的伏笔(foreshadowing.jsonl)
- 当前章节是否已到某伏笔的 `payoff_ch`(回收章)?
- 若到 → 本章兑现了吗?(没兑现 → 提醒"该写 f0xx 了")
- 悬置过久(已超 payoff 预计卷数)→ 提醒"伏笔悬置过久"

### 2. 该出现的角色戏份(fate-responsibility.jsonl)
- 当前卷是否到某角色的 `responsible` 戏份规划卷?
- 若到 → 该角色本章/本卷有戏份吗?(无 → 提醒"fr0xx 该出场了")
- 命运改写负责制:被改命的角色**必须持续有戏份**,不是"获救后变背景"

### 3. 蝴蝶效应下游(butterfly-ledger.jsonl)
- 已登记改动的锚点,下游**排了吗**(状态=已重排)?
- 有"已登记未重排" → 提醒"蝴蝶效应需重排下游"

### 4. 跨卷承诺(timeline/facts)
- 前卷立下的承诺/伏笔,到该兑现卷了吗?

## 报告模板
```markdown
# 章节衔接检查报告(ch00X)
✅ 该兑现伏笔: f0xx(本卷)已兑现 / ⚠️ f0xx(本卷)未兑现,需补
✅ 该出现角色: fr0xx(绘梨衣·卷五创伤)戏份到了 / ⚠️ 未出现
✅ 蝴蝶效应: 无待重排 / ⚠️ b00x 已登记未重排
✅ 跨卷承诺: 正常 / ⚠️ 前卷承诺逾期
> 建议: 仅为提醒,是否现在兑现由作者裁决。
```

## 与现有衔接
- foreshadowing.jsonl / fate-responsibility.jsonl / butterfly-ledger.jsonl → 数据源。
- continuity-engine(确定性检查)→ 硬查逻辑;本报告 → 提醒"该兑现什么"(前瞻)。
- quality-division.md → 软质量(节奏/共鸣)不量化,交人裁决。

## 使用
- 每章写完(质量门前)跑一次,生成报告。
- 报告进创作数据面板"创作意见区"。
