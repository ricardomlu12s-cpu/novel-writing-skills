# 数据飞轮:自进化学习闭环

**核心**:每章产出后沉淀"经验",下一章装配时注入,让系统**越写越好**——从"记得故事"升级为"从自己的写作中学习"。

## 飞轮两环
```
【回写环(已有)】章节产出 → 正典账本 → 装配下章 → 一致性更强
【学习环(本机制)】章节产出 → 质量门结果+意见+手法得失 → lessons.md → 下章注入 → 越写越好
```

## ⚠️ 飞轮防污染(最高优先级铁律)

**飞轮绝不能把"错误经验"吸收进去。** 三条硬规则:

1. **证据门槛**:任何一条 lessons 必须有**明确来源**才可写入——质量门通过/读者正向反馈/检测清除记录。**"我觉得这样好"这种主观判断不得写入**。
2. **分层可信度**:
   - `Keep(有效)`:仅当**质量门通过 + 读者正向反应/情绪曲线达标**。
   - `Stop(失效)`:仅当**质量门卡住 + 读者明确差评/检测命中**。
   - `Avoid(避坑)`:仅当**检测/质量门确认**(如禁用词命中)。
   - **无来源的"教训"标 `低置信`,默认不注入**,只归档供人工审。
3. **错误反馈隔离**:被质量门**打回**的章节、被 remove-ai-tone **判定 AI 味**的段落、被 apply-feedback 判 **C-重(需动大纲)** 的意见——这些是"错误样本",**绝不进 Keep 区**;只记入"避坑"作反面教材(Stop/Avoid),且需证据。

## 污染自检(每次沉淀前问 3 句)
- 这条有**质量门/读者/检测**的明确证据吗?(无 → 不写)
- 这条是**经验**还是**偶然**?(单次巧合 → 不写,等复现)
- 这条来自**正确样本**还是**错误样本**?(错误样本只进 Stop/Avoid,不进 Keep)

## lessons.md(写作经验库)
存于 `<项目目录>/lessons.md`。每章后追加:
```markdown
## 第12章 沉淀
### 有效的(Keep)[证据:质量门通过+情绪曲线达标]
- 这章打脸用了"延迟反噬",读者反应好 → 后续可复用此手法
### 失效的(Stop)[证据:读者差评]
- 反派降智被吐槽,下章要恢复其智商在线
### 待改进(Improve)[证据:张力值未达标]
- 这章高潮张力值只到6,读者说不够 → 下章目标拉到8
### 避坑(Avoid)[证据:检测命中]
- 别用"嘴角微扬"(读者指AI味) → 已入禁用词
### 读者反馈摘要
- 意见A(章内):处理为A类微调,已改
- 意见C(受控):金手指副作用,已级联更新
```

## 沉淀时机(每章质量门后强制)
1. **质量门结果**:门禁过了没?哪些项卡过(一致性/风格/节奏)?
2. **读者反馈**:apply-feedback 处理的意见(分级+处置+结果)。
3. **手法得失**:这章哪种手法(爽点五阶段/高潮调度/声线/反套路)奏效/失效。
4. **检测反馈**:remove-ai-tone 命中哪些模式(已清除+记入避坑)。

## 注入时机(写下一章前)
装配上下文时,注入 **最近 3 条 lessons**(不是全部,防上下文膨胀):
```
最近3条沉淀:
- 打脸延迟反噬有效,复用
- 反派智商在线,勿降智
- 高潮目标张力8
```
- 只注入**有证据**的;`低置信` 条目不自动注入。
- 与分层摘要/RAG 并列注入,不冲突。

> **⚠️ 五级分层升级(evolve-style)**:本飞轮管 **L1 章内即时学**(每章质量门后追加)。L2 情节学 / L3 弧段学 / L4 卷学 / L5 全书学 归 **evolve-style** 引擎(节律驱动)。**注入方向**:能力画像薄弱维度 → 定向取该维度 lessons 注入,替代单纯"最近3条"。

## 防 token 膨胀
- lessons.md 只追加(每章 3-6 条),写满后**压缩归档**(旧 lessons 合并为"本书长期技法"一节)。
- 注入只取最近 3 条,恒定大小。

## 飞轮成熟度(自我提升的体现)
- **早期**:从零判断,可能重复踩坑。
- **中期**:lessons 累积,避坑清单生效,手法复用。
- **成熟**:形成"本书的独特写法"(风格指纹 + 读者偏好 + 手法库),越写越贴合读者、越写越避坑。

## 衔接
- 质量门(write-chapter)、读者反馈(apply-feedback)、去AI味(remove-ai-tone)、情绪曲线(plan-plot) → 全部产出入 lessons。
- 下一章装配(记忆同步步骤) → 注入最近 3 条。
