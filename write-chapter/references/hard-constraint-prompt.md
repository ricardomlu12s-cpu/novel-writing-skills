# 硬约束 Prompt 注入模板

在调用 AI 生成战斗/世界观场景前,注入"硬约束",防设定杂糅与法则遗忘。

## 模板
```markdown
【世界观设定圣经(Prompt 约束示例)】
当前地图: <云州下界(战力上限:金丹期)>
当前力量法则:
1. <灵力不可凭空产生,施展高阶神通必须消耗灵石或抽取血气>
2. <越阶规则:筑基期无法单凭肉身击穿金丹期护体罡气,除非借助"破法符"剥离>
3. <金手指限制:主角的"解析之眼"每发动一次,视力下降50%,持续半个时辰>
要求:生成后续战斗时,严格遵循以上三条法则,凸显主角利用"破法符"与"弱点解析"的智斗过程,严禁写出直接靠意志力爆种反杀。
```

## 硬约束来源
- `power-system.md`(战力等级/边界/克制)。
- `world.md` L1 公理(世界规则)。
- 角色卡金手指限制。

## 何时注入
- 生成战斗/关键场景前(而非写完整章后补)。
- 每次注入,不靠模型"记得"设定。

## 防雷点
- **设定杂糅**:注入明确"当前地图/战力上限",防止 AI 混入高阶概念。
- **法则遗忘**:每次生成前重申三条硬法则。

## 与 rag-recall 衔接
- 硬约束 = 即时注入的"当前规则";RAG = 历史原文回读。两者互补。
