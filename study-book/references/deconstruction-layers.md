# 七层拆解规范(Deconstruction Layers)

原作是**矿藏**,本规范定义 L1-L7 每一层挖什么、怎么挖、产出什么。产物 schema 见 `source-canon-schema.md`,执行流程见 `multi-pass-protocol.md`。

## L1 细节矿 — 世界的颗粒

**挖**:让世界"活"的微小真实。
- 关键道具(玉佩/信物/武器,出现章、形状、含义)
- 标志性场景(主角初登场地/重要地标,视觉细节)
- 角色习惯用语/口头禅/标志性动作(不是台词,是行为指纹)
- 世界观里的"日常肌理"(货币体系/交通方式/市井气息)

**为什么重要**:同人文的"真实感"很大程度来自这些颗粒。搬细节不搬台词,是同人写作的合法地基。

**产物**:canon.md 的「标志性细节」区 + facts.jsonl。

## L2 伏笔全景 — 已填 + 未填

**挖**:原作**所有**伏笔,分两类。
- **已回收**:埋设章(`opened_ch`) + 回收章(`payoff_ch`)、回收方式。
- **未填(坑)**:埋设章 + 现状,标注"作者留下的未兑现承诺"。

**关键**:同人文最大的资源是**未填的坑**——续写这些坑 = 天然的高张力和读者期待。已填的坑则给你**因果范式**(作者怎么收)。

**产物**:foreshadowing.jsonl(状态:已回收/未填)。

## L3 隐藏信息 — 谁知道什么

**挖**:秘密/误导/悬念,以及**信息的分发时序**。
- 每条秘密:内容、谁先知道(`seen_by`)、何时揭示(`revealed_ch`)、是否误导(`is_red_herring`)。
- 读者知道但角色不知道的信息(戏剧反讽的来源)。

**产物**:secrets.jsonl。schema 对齐 write-mystery 的线索账本(`seen_by/revealed_ch/is_red_herring`)。

## L4 时间线 — 因果时序重建

**挖**:把原作的**叙述顺序**重建成**因果时间序**。
- 每条事件:发生时间、源作章节(`src_ch`)、叙述序 vs 因果序差异(倒叙/插叙/多线)。
- 标注时间跳变、回忆嵌入、多线并行。

**为什么重要**:这是 Phase 2"打乱重排"的前提——**只有先重建真实时序,才能重新排布叙事**。

**产物**:timeline.md。

## L5 角色本源 — OOC 守卫的基础

**挖**:每个核心角色的**本源**,这是同人防 OOC 的基准。
- 本源身份/核心欲望/行为边界(他绝不会做什么)
- **分类标记**:固定角色 / 可变角色 / 混合(决定守卫强度)
- **OOC 硬红线**:固定角色在什么情况下"崩人设"(显性列表,强约束)
- **可演化区**:可变角色因蝴蝶效应可松动的边界 + 演化合理性门槛
- **反压缩区**:内在矛盾/未展开侧面/成长开放性(防"形象压缩")
- **源作基线 vs 同人演化双轨**:Phase 3 记录蝴蝶效应导致的形象/结局变化
- 声线(口头禅/句式/回避话题,搬行为指纹)
- 知识边界(知道什么/不知道什么 → 对齐 POV)

**三条铁律**(用户指定,驱动本层设计):
1. **固定角色不能 OOC** → 分类标记 + 硬红线强约束。
2. **蝴蝶效应可改部分角色** → 可变角色可演化,但必须有因果动机、有合理性,并记录双轨。
3. **不压缩人物形象** → 反压缩区强制保留矛盾面/未展开侧面/成长开放。

**产物**:characters/<角色名>.md(源作卡)。

## L6 世界观骨架 — 体系融合基准(世界框架守恒)

**挖**:世界的**L1 公理层**(永不漂移的规则)。
- 世界规则/力量体系/势力格局/地理历史
- **守恒层级**(最高铁律):
  - **S级·绝对公理(不可穿透)**:世界最底层规则,蝴蝶效应/融入元素都不可改变(违反=破坏世界背景框架)。
  - **A级·硬框架(改动需登记)**:力量体系/势力格局/地理/时代,可调但须沿因果链重排 + 显式登记,不与 S 级矛盾。
  - **B级·弹性(可合理演化)**:细节/内部结构,可演化但守世界内在逻辑。

**为什么重要**:蝴蝶效应再大,人物/剧情可以变,**世界背景框架必须守恒**。这是比"角色不OOC"更硬的一层约束——角色是角色,世界是角色活动的舞台,舞台的地基不能塌。

**产物**:canon.md 的「世界观骨架」+「守恒层级」区。

## L7 因果链 — 打乱重排的输入

**挖**:事件之间的**因果关系图**,不是流水账。
- 每条因果:`cause 事件 → effect 事件`(谁导致谁)
- 标注关键分岔(某个选择改变了剧情走向)
- 标注"迟到原因"(作者为悬念而隐藏的因果)
- **蝴蝶效应锚点**:哪些事件是"因果分岔点"——同人一旦改变,下游连锁。
- **因果链规则**:改锚点必须重排下游;未触及的因果线忠于原作(防因果脱缰)。

**为什么重要**:同人文必然有蝴蝶效应(融入因素改变因果),但**蝴蝶效应必须挂在明确的因果线上**——改一个锚点,下游因果链必须同步重排,不能只改结果不排因果。这是 L7 的核心。落地追踪见 `butterfly-ledger.jsonl`(写作中追加:登记→重排→兑现,防脱缰)。

**产物**:causality.md。这是 Phase 2 生成「重排后大纲」的输入。

## L8 文化/时代守恒 — 源作生活世界纹理

**挖**:书中概念的现实文化根 + 时代/地域/神话三维的源作真实状态。
- **文化溯源**:书中概念 → 现实文化来源(神话原型/制度映射/民俗根基/器物象征/地理时代)。产物 `cultural-roots.jsonl`。
- **时代守恒**:年份坐标 + 科技物证(防时代错位,如把 2010s 后期智能物证写进 2010 年代初)。
- **地域文化守恒**:不同地域卷(日本卷 vs 欧美学院)的源作真实状态(防文化张冠李戴)。
- **神话守恒**:神话体系(北欧/龙神话)源作真实状态(防神话混淆)。
- **编写时转化**:现实文化根 → 书中概念(嫁接/映射/反用,守 L6 守恒)。

完整方案见 `references/cultural-sourcing.md`。

**为什么重要**:同人/创作的世界观要有"文化根脉",不悬浮;防常识性冲突(时代错位/文化张冠李戴/神话混淆)。

**产物**:cultural-roots.jsonl + 时代/地域/神话守恒表。

## 挖掘优先级(资源有限时)

1. **L2 伏笔 + L3 隐藏信息**(同人最依赖的资源)
2. **L5 角色本源 + OOC 红线**(防崩的底线)
3. **L7 因果链**(重排的燃料)
4. **L1 细节 + L4 时间线 + L6 世界观**(地基,可并行补齐)
5. **L8 文化/时代守恒**(厚度的来源,世界观深挖时补)

## 与"手法吸收"的分工

- **本引擎(拆书)**:忠于原作的内容。挖的是"原作里到底有什么"。
- **learn-style(吸收)**:脱离原作的手法。学的是"作者怎么写"。
- 同一部作品可以两个都跑:先拆书立基准,再吸收定文风。
