# 设定来源标签 + 大事件锚点状态机(通用,同人/原创皆适用)

**问题**:任何长篇创作里,一条设定/一个事件都有"确定性层级"之分——已锁定的规则、借鉴来的元素、高可信推断、留白未定、本次自创。混着用会:把借鉴当成原创、把推断写成铁律、把留白写成定论、把自创设定混进"既成事实"。缺一套**来源标签 + 事件状态追踪**,追不了源。

> 通用机制。同人只是特例:同人有"源作基准线(source-canon)",来源标签落到"哪个版本/哪本书";原创的"源"是"本项目已定规则 + 借鉴的作品"。

## 1. 设定来源标签(每条关键设定标注确定性层级)

| 标签 | 含义(通用) | 同人语境下的对应 |
|---|---|---|
| **LOCKED** | 本项目已锁定的规则/事实(不可随意改) | 当前采用的修订版明确设定(R-CANON) |
| **BORROWED** | 从其他作品借鉴/融合的元素 | 旧版/重启版/辅助书的设定(O-CANON/REBOOT) |
| **INFERRED** | 根据已定规则的高可信推断 | 根据明确设定的高可信推断(CANON-INFER) |
| **UNSET** | 尚未定/留白/存在多种解释 | 原作留白/版本差异/解释争议(AMBIGUOUS) |
| **ORIGINAL** | 本次创作新增设定 | 同人当前世界新增设定(CUSTOM) |

**铁律**:
1. 禁止把 UNSET 写成绝对定论。
2. 禁止把 BORROWED 当成 LOCKED(借鉴不是原创,防缝合怪)。
3. 无法确定时,宁可保持模糊(留白也是创作空间)。
4. LOCKED 与 BORROWED 冲突时,以 LOCKED 为准(本项目规则 > 借鉴来源)。

### 落地位置
- build-world 的 `world.md` / 角色卡 / 力量体系:凡涉"借鉴/推断/留白"的设定,条目上标 `tag: LOCKED / BORROWED / INFERRED / UNSET / ORIGINAL`。
- 同人项目:拆书产物 `source-canon/canon.md` 元信息加"采用的正典版本 + 取舍铁律",源作条目按上述对应打标签。

## 2. 大事件锚点状态机(大纲大事件节点追踪)

**问题**:长篇里每个"大事件"(大纲里的关键节点)当前处于什么状态——还没铺垫?正在铺垫?发生了?被主角改变了?被跳过了?缺追踪,写到后面会"事件对不上"。

为每个大纲大事件维护一条:

```
EVENT-ID 事件名 预计时期 前置条件 必要人物 必要地点 必要伏笔 核心矛盾 触发条件 原定结果 当前状态
```

状态机:

| 状态 | 含义 |
|---|---|
| PENDING | 前置条件未满足,事件未开始 |
| FORMING | 条件正在形成(线索/征兆已出现) |
| ACTIVE | 事件已开始 |
| ALTERED | 事件发生但结果被改变 |
| RESOLVED | 事件按原定结果收束 |
| SKIPPED | 事件被跳过(剧情改道,不再发生) |
| INVALIDATED | 事件的历史条件已永久消失 |
| SPLIT | 产生了分叉路线(多版本并存,需显式记账) |

### 状态机铁律
- 状态只能沿因果推进,**不能"已 SKIPPED 又变回 ACTIVE"**(除非有新的因果解释)。
- 事件被跳过 → 记 SKIPPED + 蝴蝶效应/因果账本登记(下游事件重排)。
- SPLIT 仅在明确写分叉路线时用,且必须逐项记录差异。

### 落地位置
- 大纲阶段(`plan.md` / `chapter-outlines/`)列出大事件节点,给每个标初始状态。
- 写作中事件状态变化 → 回写。
- write-chapter 连续性校验加一条:本章若触及某大事件,核对它的当前状态是否与正文一致(如已 SKIPPED 的事件不能又"按原计划发生")。
- 同人项目:这些"大事件"就是原著事件(拆书产出 `canon-events.jsonl`,源作只读)。

## 3. 与现有机制的接缝(不重复)

| 已有 | 本机制补什么 |
|---|---|
| butterfly-ledger(改锚点→重排下游) | **锚点当前状态**——账本记"改了什么",本机制记"事件现在处于什么状态" |
| foreshadowing(伏笔状态机) | 伏笔是"信息线索",事件锚点是"剧情大节点",二者并行不重复 |
| 原创/同人的"来源" | 标签系统让"原创 vs 借鉴 vs 留白 vs 自创"可执行——每条设定标了来源,取舍才有依据 |

## 4. 接入

- build-world 建设定阶段:给设定打标签 + 列出大事件节点状态。
- study-book(可选拆书,原创借鉴时也用):产出事件锚点 + 给借鉴来源打标签。
- write-chapter 连续性校验:加"大事件状态核对"一项。
- build-world 面板:可加"大事件锚点状态"区。
