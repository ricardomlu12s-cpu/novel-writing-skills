# 体系差异磨合协议(System Integration Protocol)

**引入的体系/因素与原世界观相差较大**时,要思考怎么完美融合。本协议定义:外来体系怎么接入主书世界而不打碎其背景框架。

## 核心:守恒级 + 磨合桥梁

融合的底线 = **主书世界框架守恒(S 级绝对公理不可穿透)**。外来体系再强,不能覆盖主书公理,只能**补充/借位/改造**。

## 磨合三问(每引入一外来体系前)

1. **外来公理触及主书框架哪一级?**(S/A/B,见 canon.md 守恒层级)
2. **与 S 级绝对公理冲突吗?** → 冲突必须改造或拒绝,不能硬注入。
3. **磨合桥梁是什么?** → 怎么接入不打碎原世界。

## 三种磨合桥梁

| 桥梁 | 含义 | 例子 |
|---|---|---|
| **补充** | 外来体系填补主书空缺,不覆盖 | 《XX》灵气体系补充主书力量体系空白 |
| **借位** | 外来元素借用主书已有体系的位置/通道 | 外来"道法"借主书"宗门传承"载体落地 |
| **改造** | 外来公理改写以适应主书公理 | "死后轮回"改为"残念存留"(不违反人死不复生) |

## 步骤

1. **识别外来公理**:从引入体系里抽出核心公理(规则/力量/因果)。
2. **过守恒三问**:逐条判断触及主书框架哪级。
3. **冲突处理**:
   - 与 S 级冲突 → **改造**(改到兼容)或 **拒绝**(放弃该公理)。
   - A 级 → 登记 + 沿因果链重排。
   - B 级 → 可融入,守世界逻辑。
4. **登记**:写进 `external-axioms.jsonl`(axiom / source_book / target_level / compat_with_s / bridge / status)。
5. **已磨合才可写正文**:外来公理 `status=已磨合` 后才能进入正文;否则视为未登记设定冲突。

## 与守恒级联动

- 外来体系 = 一堆公理 → 每条挂主书框架 S/A/B 级。
- **S 级冲突是硬边界**:任何外来公理不得改变主书"人死不复生"这类绝对公理(除非原作本就如此)。
- 外来体系引入本身也是**蝴蝶效应锚点** → 进 `butterfly-ledger.jsonl`,沿因果链重排下游。

## 防雷点

- **设定杂糅**:外来体系未登记就混入正文 → 缝合怪。
- **法则遗忘**:已磨合的公理,写作时要注入(硬约束),不能靠模型记得。
- **公理覆盖**:外来公理盖过主书 S 级公理 → 世界框架崩塌。

## 产物

- `external-axioms.jsonl`(外来公理登记,见 source-canon-schema.md)。
- 与 `merge-registry.jsonl`(融合来源)、`butterfly-ledger.jsonl`(蝴蝶效应)联动。
