# L8 文化溯源层(Cultural Sourcing & Two-Way Conversion)

**书中概念不是凭空来的——它往往映射现实文化来源。** 拆书时溯源(书中→现实),编写时转化(现实→书中)。这是世界观的"文化根脉",让同人/创作有厚度、不悬浮。

## 双向转化核心
```
拆书时: 书中概念 → 现实文化来源(溯源)
  例: 龙族的"卡塞尔学院" → 现实中的西方精英大学/共济会式秘密社团文化
编写时: 现实文化来源 → 书中概念(转化,不照搬)
  例: 借鉴"屠龙传说"的现实原型(圣乔治屠龙) → 转成书中的"龙族与混血种"设定
```

## 拆书时:书中概念 → 现实文化来源(溯源)
挖每个关键概念背后的**文化根**:
| 概念类型 | 溯什么源 | 例(龙族) |
|---------|---------|----------|
| **神话题材** | 神话/传说的现实原型 | 龙王/混血种 → 北欧神话(尼德霍格)、西方屠龙传说 |
| **制度设定** | 现实制度的映射 | 卡塞尔学院 → 精英寄宿学校/秘密结社(共济会式) |
| **民俗/仪式** | 民俗学的现实来源 | 言灵/血统 → 巫术/血统论的民俗学根基 |
| **器物/象征** | 物件的文化象征 | 龙骨/鳞 → 龙图腾在中国/西方的不同象征 |
| **地理/时代** | 历史地理的对应 | 卡塞尔在芝加哥 → 美国精英教育的地理文化 |

**产物**:`source-canon/cultural-roots.jsonl`
```json
{"concept":"卡塞尔学院","root":"西方精英大学+秘密社团文化","book_usage":"主角成长舞台","convert_note":"写新场景时可映射现实校园权力结构"}
```

## 编写时:现实文化来源 → 书中概念(转化)
**转化≠照搬**,要把现实根"书中化":
1. **转化三问**:
   - 这个现实文化,书中世界**有对应物吗**?(有→深化;无→可嫁接)
   - 转化后**符合世界框架吗**?(S/A/B 守恒,查 L6)
   - 转化是**服务主题/人物**,不是炫学(避免掉书袋)?
2. **转化方式**:
   - **嫁接**:现实文化元素融入书中设定(如现实校园的权力斗争 → 卡塞尔的家族政治)。
   - **映射**:书中概念在现实有原型,深化其"文化内涵"(言灵 → 言灵术的原始信仰)。
   - **反用**:现实文化的反面(现实"屠龙是正义" → 书中龙可能是被误解的一方)。

## 与现有层衔接
- **L6 世界观骨架**:文化溯源服务于世界框架(溯源让设定有根,但转化仍守守恒)。
- **L7 因果链**:文化根影响因果(某个设定源自某文化 → 因果带文化色)。
- **learn-style 吸收**:拆书溯源(忠于原作)+ 吸收手法(脱离原作),互补。
- **知识库(write-mystery)**:文化溯源的现实知识入生/心/社/哲知识库。

## 检查清单(每次溯源/转化)
- [ ] 拆书时:关键概念溯源到现实文化了吗?(cultural-roots.jsonl)
- [ ] 溯源是"服务设定"不是"堆学术"?(有厚度,非炫学)
- [ ] 编写时:现实根转化回书中概念了吗?(不照搬现实)
- [ ] 转化三问过了吗?(有对应物/守守恒/服务主题)
- [ ] 转化符合世界框架吗?(S/A/B 守恒)

## 与同人协议的关联
- 同人尤其需要:源作设定往往映射现实文化 → 溯源让同人的"再创作"有文化根(不是瞎编)。
- 转化时仍守同人三铁律(世界守恒/不OOC/不压缩)。
