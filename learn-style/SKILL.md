# Style Learn — 风格学习吸收

从**你喜欢的作品**里提取可吸收的创作要素,融入自己的创作,**不是复制粘贴**。核心理念:**吸收"手法",不搬"台词";学习"思路",不抄"情节"**。

## 0. 输入方式
- **导入文本**:把作品片段/文件给进来(路径或粘贴)。支持单章、短篇、多章。
- **报作品名**:只给书名/作者名 → 用 WebFetch/deep-research 查官方或可靠来源的写作特点(慎防二手失真,优先原文片段)。
- **整部作品/多部作品**:输入全文文件 → 跑**多维吸收采样**(见下节),自动定位 5-15 个代表片段吸收,不简陋、消耗可控。
- 可**多源**:"借鉴 A 的留白节奏 + B 的对白密度" → 合成独特风格。

## 0.5 整部作品吸收(多维采样)
- 完整方案见 `references/absorption-sampling.md`。
- 输入作品全文 → 跑 `scripts/sample_for_absorption.py`:
  - 全貌扫描(句长/标点/高频词,脚本统计免费)。
  - 7 维定向采样(风格/语言/内涵/人物/情节/世界观/情感)→ 5-15 段代表片段。
  - **作品学习价值画像**:标注最强维度 → 决定吸收重点。
- 只在采样片段上做深度提取(不在全文),一次性几万 token,风格库永久复用。
- 多部作品 → 各自画像 → 按需加权融合(要 A 语言 + B 内涵 + C 风格)。

## 0.6 防缝合融合 + 配方指定
- **防缝合**:多源融合必须"消化吸收,非加法拼贴"——主从底盘 + 冲突消解 + 内核优先。方案见 `references/anti-sewing-merge.md`。
- **配方指定**:可精细指定"哪部作品的哪个成分 → 这本书的什么"(如 底盘=A 风格,调味=B 对白)。模板见 `references/merge-recipe.md`。
- **注入方式**:按配方分层注入(写对话用 B,写世界观用 C),不模糊混合。
- **融合后自检**:跑防缝合检测(主从分明?冲突消解?内核优先?自洽?),有拼贴感 → 调配方。

## 1. 提取三维风格指纹
完整维度与报告 schema 见 `references/style-fingerprint.md`。核心三维:

| 维度 | 提取什么 |
|---|---|
| **文风** | 句式节奏、词汇偏好、标点习惯、叙述视角、留白密度、修辞手法、情感浓度 |
| **角色** | 刻画手法(外貌/动作/心理/对白比例)、对白风格、内心独白节奏、成长弧线处理 |
| **情节** | 结构模式、冲突类型、悬念手法、伏笔节奏、高潮设计、收束方式 |

## 2. 生成「风格吸收报告」
报告必须含**三个标注区**,这是"不硬搬"的关键:
- **吸收(Adopt)**:哪些手法可以内化(如"短句+大量留白制造紧张")。
- **规避(Avoid)**:哪些不能直接搬(如"原作的独特设定名""标志性台词""过度辨识的句式")。
- **融合(Merge)**:多源时如何合成(如"A 的节奏 × B 的对白密度 × 自己的主题")。

报告写入风格库:
```
.omc/style-library/<风格名>/fingerprint.md   # 三维指纹(作为 evolve-style 的"目标指纹"基准)
.omc/style-library/<风格名>/report.md         # 吸收/规避/融合 报告
```
> **双轨指纹接缝**:fingerprint.md 是 evolve-style 双轨对比的**目标指纹**(静态基准);进化引擎维护"实际指纹"(已写定稿)并检测"锁死区"(偏差≈0→防固化)。本 skill 更新指纹时,evolve-style 自动读取对比。

## 3. 创作时注入(不硬搬)
- 创作 skill(write-chapter / build-world)启动时,读取 `.omc/style-library/<风格名>/report.md` 的 **Adopt 区**,作为风格约束注入 prompt。
- 显式规则:**引用手法,不引用原文**;若某段接近原作,标"撞车风险"并改写。
- 风格库可跨项目复用(一个风格供多个故事使用)。

## 4. 风格校准(借鉴 novel-creator-skill 门禁)
- 每章完成后,对照风格指纹做**风格漂移检查**:偏离 → 校准;过度模仿 → 拉回。

## 喂给谁 / handoff
- **build-world**:风格指纹里的角色刻画手法 → 人物卡写法参考。
- **write-chapter**:风格约束注入 + 每章风格校准。
- **remove-ai-tone**:风格指纹可辅助判断"哪些是刻意风格,哪些是AI味"(区分),避免误伤。
- **study-book(同人)**:本 skill 吸收的是**手法**(怎么写);拆书引擎提取的是**内容忠实地基**(原作里有什么)。同人文两者都需要:先 study-book 拆书立源作设定库,再用本 skill 定文风。**分工:拆书=内容,风格吸收=手法。**
- 产物:`.omc/style-library/<风格名>/`(fingerprint.md + report.md)。
