# 融合配方指定(Merge Recipe)

用户可**指定"哪部作品的哪个成分,做这本书的什么"**——像调配方,细粒度控制,不是模糊混合。

## 配方模板
```markdown
# 融合配方: 《作品名》
## 底盘(主风格,全书基调)
- 来源: 《A》的风格节奏 → 作用: 全书基调
## 调味(辅助层)
- 来源: 《B》的对白密度 → 作用: 对话场景
- 来源: 《C》的世界观深度 → 作用: 世界观设定
## 人物/情节/情感
- 人物: 《D》的角色刻画 → 主角塑造
- 情节: 《E》的悬念手法 → 高潮安排
- 情感: 《F》的情绪曲线 → 共鸣设计
## 规避(防硬搬)
- 《G》的设定名/台词 → 不搬
## 边界
- 每个成分只用于其指定层,不越界
```

## 成分标注(每成分必填)
| 字段 | 含义 |
|------|------|
| 来源 | 哪部作品 |
| 成分 | 哪个维度(风格/语言/人物/情节/世界观/情感) |
| 作用 | 在这本书里做什么(基调/对话/世界观…) |
| 边界 | 只用于该层,不越界 |

## 注入方式(按配方,非混合)
- 创作时**按配方分层注入**:写对话用 B 的成分,写世界观用 C 的成分,全书基调用 A。
- 不模糊混合(A+B+C 全混在一起 → 缝合怪)。

## 配方检查(防缝合)
- 底盘明确?(有且仅有一个主)
- 成分分层?(各管各的层,不越界)
- 规避到位?(不硬搬设定名/台词)
- 冲突消解?(冲突维度已定主次)

## 示例
```markdown
# 融合配方: 《青云志》
- 底盘: 《诡秘之主》的克制叙事 → 全书基调
- 调味: 《凡人修仙》的白描 → 修炼场景
- 人物: 《诛仙》的挣扎刻画 → 主角塑造
- 情节: 《雪中》的章末钩子 → 高潮安排
- 规避: 各部作品的具体人名/地名/招式名
```

## 与防缝合衔接
- 配方指定 = 精确控制"哪个成分做哪层"。
- anti-sewing-merge.md = 融合后自检(主从/冲突/内核)。
- 两者配合:配方定结构,防缝合定自检。
