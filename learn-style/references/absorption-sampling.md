# 多维吸收采样(Absorption Sampling)

输入作品全文,自动定位 5-15 个**代表性片段**吸收。**不简陋**——不同作品值得学的维度不同(风格/语言/内涵),按维度定向采样,非一刀切。

## 核心设计
```
① 全貌扫描(轻量,不读全文):结构识别 + 句长/标点/高频词统计 + 特殊段落定位
② 多维定向采样(7 维,每维 1-3 段 → 共 5-15 段/1-2 万字)
③ 按维度提取指纹(复用 style-fingerprint.md 三维 + 扩展)
④ 作品学习价值画像(标注最强维度 → 决定吸收重点)
⑤ 多部融合(按需加权)
```

## 7 个可学维度
| 维度 | 学什么 | 采样定位 |
|------|--------|---------|
| **风格** | 句式节奏/词汇偏好/留白密度/视角 | 全篇分散取 3-4 段代表性段落 |
| **语言** | 修辞/比喻/通感/句法/标点 | 高修辞密度段(比喻/排比密集处) |
| **内涵** | 主题/价值观/世界观深度/思辨 | 角色思辨段/关键对白/结尾升华 |
| **人物** | 动机/行动化呈现/声线/刻画手法 | 高对白密度段 + 内心独白段 |
| **情节** | 因果动能/悬念/高潮/反转/伏笔 | 高潮爆点段 + 伏笔段 + 收束段 |
| **世界观** | 规则/战力/资源/阵营/设定 | 设定说明段 + 战力描述段 |
| **情感** | 情绪曲线/爽点/虐点/共鸣 | 情绪高潮段(虐/燃/爽) |

## 全貌扫描(轻量,低成本)
用脚本统计,不读全文:
- 结构:章节/卷边界识别。
- 句法:句长分布、标点频率(逗号/句号/省略号/破折号)。
- 词汇:高频实词、独特用语。
- 特殊段落定位:高对白密度、高修辞密度、长段内心独白、情绪词密集段。

## 作品学习价值画像
提取后输出:
```markdown
# 学习价值画像:《作品名》
- 最强维度: 语言肌理(比喻/通感极强)
- 次强维度: 人物(声线鲜明)
- 弱维度:   内涵(主题较浅)
- 建议吸收重点: 语言 + 人物;内涵可略
```
→ 决定这部作品**最值得学什么**,吸收时重点倾斜。

## 多部融合
- 每部各自价值画像 → 按需加权:
  - "要 A 的语言 + B 的内涵 + C 的风格" → 融合时各维度取最强来源。
- 融合进 learn-style 的风格库(吸收/规避/融合)。

## 消耗
- 全貌扫描:脚本统计,免费。
- 定向采样:每维 1-3 段,共 5-15 段(1-2 万字)。
- 深度提取:只在采样片段上做(不在全文)。
- 一次性几万 token;风格库永久复用,每章注入薄指纹(几百 token)。

## 脚本
`scripts/sample_for_absorption.py`:
- 输入:作品全文文件。
- 输出:代表片段清单(按维度标注)+ 价值画像数据。
- 深度提取(LLM)在采样片段上做,脚本只做定位与统计。

## 与现有衔接
- 吸收报告(stype-learn 已有):采样片段 → 提取 → 吸收/规避/融合。
- 每章注入:风格指纹(薄),不灌全文。
