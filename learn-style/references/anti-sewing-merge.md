# 防缝合融合机制(Anti-Sewing Merge)

投喂多部作品若吸收不好 → "拼贴感"(缝合怪)。核心:**消化吸收,不是加法拼贴**。

## 缝合怪根因
| 错误(缝合怪) | 正确(消化) |
|-------------|-----------|
| 并列堆叠:A风格+B桥段+C人设硬拼 | 主从底盘:定一个底盘,其他调味 |
| 每样都学一点:全都要 | 抓住内核:学"为什么好看" |
| 不设边界:互相打架 | 冲突消解:定主次 |

## 三层防缝合机制

### 1. 主从底盘(避免并列堆叠)
- 每本书定**一个底盘**(主风格/主内核),其他作品只做**调味**。
- 例:A 留白节奏(底盘) + B 对白密度(调味) + C 世界观(辅助)——**主从分明**。
- 判断:去掉调味,底盘是否仍自洽?是 → 底盘成立。

### 2. 冲突消解(防互相打架)
- 多源吸收时检查**维度冲突**:A 抒情节奏 vs B 硬核风格。
- 冲突时**定主次**:服务本作主题的留,不硬塞。
- 例:本作是硬核权谋 → A 的抒情节奏让步,只保留 B 的克制风格。

### 3. 内核优先(防"表皮缝合")
- 吸收"**为什么抓人**"(内核:节奏/人物挣扎/主题),不吸收"好看的句子"(表皮)。
- 硬搬表皮 → 缝合怪;消化内核 → 融合。
- 判断:吸收后能否写出"服务本作主题"的原创表达?能 → 内核到位。

## 防缝合检测(融合后检查)
1. **主从分明**:有明确底盘吗?(不是并列堆叠)
2. **冲突消解**:维度冲突定主次了吗?(不打架)
3. **内核优先**:吸收的是内核还是表皮?(非硬搬)
4. **自洽感**:去掉来源标签,是一部自洽作品吗?(非"三本书拼贴")

## 与配方指定衔接
- 配方指定(`merge-recipe.md`)提供"哪个成分做哪层"的精确控制。
- 防缝合机制提供"融合后如何自检"。

## 使用
- 融合时:先定主从 → 消冲突 → 取内核 → 生成配方。
- 融合后:跑防缝合检测,有拼贴感 → 调整配方(改主从/去冲突成分)。
