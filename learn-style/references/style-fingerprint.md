# 风格指纹提取维度与报告 Schema

从作品提取"风格指纹"的完整维度清单与输出格式。目标是**可吸收的手法**,不是可复制的文本。

## 白金式内核维度(防"表皮缝合"——吸收为什么抓人)
在三维指纹之外,吸收**内核**(为什么这部作品抓人),不吸收表皮(好看的句子):
- **叙事势能**:这部作品靠什么驱动读者(情绪?悬念?智斗?装逼?)——这是"为什么抓人"的根。
- **人物引擎**:主角靠什么立住(执念?反差?成长?)——人设变化是否就是剧情引擎。
- **主题暗线**:表层故事之下,是否有贯穿的主题/价值观(猫腻"代安全感之上的不安全感")。
- **结构创新**:这部在哪个方向"走极端"(金手指弱化?心理白描?认知模糊?)——见 genre-innovation。
- **独特声音**:脱离文风特征后,这部作品的"声音"是什么(东方式克制?文青?热血?)。

> 吸收报告须含内核区;只有表皮(句式/词汇)没有内核 → 报告不完整,重提取。

## 一、三维指纹维度

### A. 文风(句式/词汇/节奏)
| 维度 | 提取点 | 例 |
|---|---|---|
| 句式节奏 | 长短句比例、段落长度、断句习惯 | "短句密集→紧张;长句舒缓→沉思" |
| 词汇偏好 | 高频实词、文言/口语比例、方言、行业词 | "爱用四字格""善用烟火气俗语" |
| 标点习惯 | 逗号密度、句号长度、破折号/省略号使用 | "大量省略号制造欲言又止" |
| **词汇丰富度** | 类符形符比 TTR(>0.50 丰富,<0.40 贫乏) | "词汇密度高,少重复" |
| **句式变化** | 句长标准差 SVR(>3 多变,<3 单调) | "长句舒缓短句密集,错落" |
| **转场习惯** | 转场词密度(避免"然而/因此"高频) | "场景切换自然,少连接词" |
| **模板度** | 段落是否「论点-解释-例子」模板化 | "结构多变,不套模板" |
| 叙述视角 | 全知/限知/第一人称、POV 切换频率 | "多POV交叉""深挖单一内心" |
| 留白密度 | 交代 vs 暗示的比例 | "只给动作不给心理,让读者猜" |
| 修辞手法 | 比喻/拟人/通感/排比偏好 | "善用通感:声音有颜色" |
| 情感浓度 | 直抒 vs 克制、煽情 vs 留余 | "克制到近乎冷漠,偶尔爆一句" |

### B. 角色(刻画手法)
| 维度 | 提取点 | 例 |
|---|---|---|
| 刻画比例 | 外貌/动作/心理/对白四者占比 | "几乎不对白,全靠动作" |
| 对白风格 | 台词长短、潜台词、口头禅、身份感 | "话少但每句都是刀子" |
| 内心独白 | 频率、节奏、是否直接引语 | "长篇内心戏+意识流" |
| 成长弧线 | 变化节奏、顿悟 vs 渐变 | "每卷一次大蜕变的打怪流" |
| 配角处理 | 是否工具人、如何侧面立人 | "配角也三笔立住" |

### C. 情节(结构/冲突/悬念)
| 维度 | 提取点 | 例 |
|---|---|---|
| 结构模式 | 单线/多线、正叙/倒叙、章末钩子 | "双线并进,章末必留钩子" |
| 冲突类型 | 外部(打斗/权谋)vs 内部(心理)比例 | "外部冲突推剧情,内部冲突立人物" |
| 悬念手法 | 伏笔密度、揭露节奏、误导技巧 | "伏笔埋三章收一章" |
| 高潮设计 | 大高潮/小高潮分布、爆点间隔 | "三章一小爽,十章一大爆" |
| 收束方式 | 圆满/开放/留白、尾声处理 | "结局留白不解释" |

## 二、风格吸收报告 Schema

```markdown
# 风格吸收报告: <风格名>

## 来源
- 输入: <导入文本路径 | 作品名 | 作者>
- 提取时间: <时间>

## A. 文风指纹
<逐维度结论,附 1-2 个手法示例,不引原文长段>

## B. 角色指纹
<逐维度结论>

## C. 情节指纹
<逐维度结论>

## 吸收(Adopt)—— 可内化的手法
- [ ] <手法 1:如"短句+留白制造紧张">
- [ ] <手法 2>

## 规避(Avoid)—— 不能直接搬的
- [ ] <设定名/台词/标志性句式>

## 融合(Merge)—— 多源合成方案
- <A 的节奏 × B 的对白密度 × 自己的主题>

## 撞车红线
- <哪些表达一旦出现即视为过度模仿,须改写>
```

## 三、使用规则
1. **只列手法,不引原文长段**(引用 ≤20 字做示例)。
2. **规避区必填**:防"硬搬"的核心约束。
3. **可复用**:风格库供多故事共享,跨项目注入。
