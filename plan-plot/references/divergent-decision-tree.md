# 卡文续写:条件约束下的发散决策树(Constraint-Based Decision Tree)

打破"卡文就让 AI 替我写"的误区。**AI 降维为参谋,给多路径方案,保留创作者最高裁决权**。

## 核心:禁止代笔
- **禁**:卡文时直接让 AI 生成正文(平庸、越权)。
- **该**:AI 做"盘面资产审计" → 提供多路径选择 → 由作者拍板。

## 第一步:盘面资产审计
写卡文场景前,先盘点:
| 资产 | 检查 |
|------|------|
| **目标** | 当前章/弧的主角目标是什么? |
| **限制** | 战力上限/规则/金手指副作用(硬约束) |
| **资源** | 已埋伏笔/可用道具/可信援军(防机械降神) |
| **矛盾** | 当前冲突哪方占优?可升级点在哪? |

## 第二步:多路径决策树
基于审计,给 **3-5 条戏剧性突发路径**(非正文,是方案):
```
路径A: 第三方势力意外闯入(有伏笔基础吗?无则标"需补铺垫")
路径B: 关键道具产生未预料副作用(符合硬约束吗?)
路径C: 角色说出隐藏多年的秘密(契合其创伤心结吗?)
路径D: 时间跳跃(跳过僵局,直切关键节点)
路径E: 改配角视角推进同一事件
```
每条标注:冲突增量 / 与伏笔的关系 / 风险。

## 第三步:作者裁决
- 作者选路径后,才由作者(或经作者确认的 AI)写正文。
- AI 不替作者决定"哪条最好",只给"每条的代价与收益"。

## 与 author-craft 衔接
- author-craft.md 的卡文破局法(换角度/缩场景/引新信息/时间跳跃/改配角视角)= 决策树的路径来源。
- 本机制把它**结构化**:先审计 → 再给选项 → 作者裁决。

## 检查清单(卡文时)
1. 先做了盘面资产审计吗?(目标/限制/资源/矛盾)
2. 给了多路径方案,还是直接代笔?(代笔 = 违规)
3. 每条路径标注了代价/伏笔关系吗?
4. 保留作者最高裁决权吗?(AI 不替选)
