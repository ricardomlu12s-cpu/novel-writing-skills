# 节奏刹车(Pacing Brake)

**剧情推进过快**(20章开一卷 / 每章都高潮)→ 世界观/人物没铺开,读者疲劳。本机制"该慢则慢"。

## 推进过快信号(命中即告警)
| 信号 | 说明 | 阈值 |
|------|------|------|
| **一卷章数过少** | 20 章一卷 = 太赶(世界观/人物没铺开) | 一卷 <30 章 告警 |
| **每章都高潮** | 张力值连续 ≥7 → 无缓冲,疲劳 | 连续 3 章张力≥7 告警 |
| **升级过密** | 战力晋级频繁 → 通胀风险 | 20 章内晋级 >2 次 告警 |
| **关系推进过快** | 好感→定情 <10 章 → 工业糖精 | 感情线 <10 章确立 告警 |
| **地图更换过频** | 换地图 <10 章 → 铺垫不足 | 10 章内换地图 告警 |

## 该慢则慢(缓冲内容)
| 场景 | 内容 | 作用 |
|------|------|------|
| **世界观铺开** | 势力/地理/历史展开(不 Infodump) | 增加厚度 |
| **人物日常** | 角色生活/互动(非主线推进) | 立人物 |
| **关系发展** | 感情/友谊渐进(非一步到位) | 真实感 |
| **铺垫伏笔** | 埋设长线(三级递现) | 后期回收 |
| **缓冲章** | 紧张后日常(张弛有度) | 读者休息 |

## 与爽点平衡
- **该快**(satisfaction-cycle):爽点五阶段该爆则爆。
- **该慢**(本机制):高潮后必缓冲,铺垫期该缓则缓。
- 平衡:爽点循环(快)× 缓冲/铺垫(慢)= 张弛有度。

## 检查清单(每卷/每 10 章)
- [ ] 一卷 ≥30 章了吗?(<30 告警)
- [ ] 连续 3 章张力≥7 了吗?(告警,插缓冲)
- [ ] 20 章内晋级 >2 次了吗?(告警,战力通胀)
- [ ] 感情线 <10 章确立了吗?(告警,工业糖精)
- [ ] 10 章内换地图了吗?(告警,铺垫不足)
- [ ] 有缓冲/铺垫章吗?(该慢则慢)

## 与现有衔接
- 爽点五阶段(该快)+ 本机制(该慢)= 节奏平衡。
- 分卷规划(volume-session-plan)→ 一卷章数建议(≥30 符合 70-100 章/卷)。
- 感情线(write-romance)→ 确立 <10 章即工业糖精。

## 防拖沓(反向:该快则快,禁止原地打转)

**问题**:节奏慢不等于拖沓。拖沓 = 连续多章没有信息增量,原地打转。

- **拖沓信号**:连续 3 章没产生「新信息 / 关系变化 / 任务变化 / 时间变化 / 资源变化 / 人物行动 / 世界变化」任一项 → 必须推进至少一项。
- **禁止无限**:无限吃饭 / 无限闲聊 / 无限准备 / 无限训练 / 无限等待。
- **缓冲 ≠ 拖沓**:缓冲章有作用(立人物/铺伏笔/关系沉淀),拖沓章没有增量。判断标准 = 删掉这章缺不缺东西。

## Recent Event Cache(近期事件缓存,防机械重复)

- 记录最近约 10 章的主要事件,避免:
  - 连续偶遇同一个角色;
  - 重复收到类似任务;
  - 反复发生同一种袭击/冲突;
  - 同样的信息被不同 NPC 重复告诉读者;
  - 重要台词机械重复(同一句口头禅连续出现)。
- **判断**:新写一章前,扫近期缓存,本章是否有"重复感"的推进?有 → 换事件/换角度/换信息。
