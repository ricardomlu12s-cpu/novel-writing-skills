# 网文常见套路库 + 破局建议

AI 爱走这些熟路。识别 → 破局 → 防重复。

## 高发套路(识别特征 → 破局建议)

| 套路 | 识别特征 | 破局建议 |
|------|---------|---------|
| 打脸 | 反派挑衅→主角秒打脸→围观惊叹 | 让打脸**延迟**或**反噬**(主角装逼被打回);打脸代价化 |
| 退婚/羞辱开局 | 开篇被退婚/赶出宗门/当众羞辱 | 不报复,反向共情退婚方也有苦衷;或开局已过去式(中盘回想) |
| 废柴逆袭 | 废物资质→奇遇→吊打天才 | 废柴的"废"要给**结构性原因**(血脉诅咒/封印),逆袭靠**代价与牺牲**非白送 |
| 系统送挂 | 系统凭空给金手指 | 系统来源**黑箱化**为伏笔;金手指有**副作用/过期/被夺** |
| 穿越开挂 | 穿越→现代知识碾压古代 | 碾压**受限**(历史/物理/语言障碍);或知识反而害主角 |
| 退婚流+赘婿+扮猪吃虎 | 三件套连用 | 拆开单用;扮猪吃虎的"猪"要有真实弱点 |
| 升级流水账 | 打怪→升级→打更大的怪 | 插入**非战斗进度**(关系/真相/代价);升级要有瓶颈与仪式感 |
| 一呼百应 | 主角遇难必有援军 | 援军**迟到/叛变/有代价**;主角独自扛一次 |

## 破局三大法
1. **打破预期**:读者以为 A 要赢 → 让 A 输,且输得合理。
2. **反转设定**:常见设定给非常规解释(如"系统"其实是反派的后门)。
3. **置换元素**:把 A 题材的套路用到 B 题材(如修仙里玩权谋,权谋里加科幻)。

## 事件冷却(防重复)
同一套路若在前 10 章内已用 → 冷却告警。衔接 novel-creator 的 `event_matrix_scheduler.py`。

## 创新度检查
每章质量门查:本章是否至少有一个"非套路推进"(新信息/新关系/新代价/新冲突),避免纯套路填充。

## 反套路黑名单(通用,补充)

以下不是"套路"而是"叙事漏洞/主角光环",一旦出现即告警:

- 第一次见面就说主角"很特殊"。
- 所有核心角色自动喜欢/认可主角。
- 强者/大佬自动重点培养主角(无合理理由)。
- 某个万能角色/系统能解决所有谜团。
- 组织毫无内部政治(铁板一块)。
- 反派为了输而降智。
- 所有任务最终都必须让主角参与;主角不参与世界就暂停。
- 救一个人自动获得永久忠诚。
- 提前知道真相(穿越/重生)自动解决全部事件。
- 所有选择最后重新回到原著/原定结局。

**核心**:世界不围绕主角运行。名声/信任/关系必须通过身份、行动、实力、关系、传播**逐渐建立**,不能开局白送。
