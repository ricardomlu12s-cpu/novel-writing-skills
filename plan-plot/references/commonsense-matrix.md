# 常识合理性矩阵(特殊题材除外)

检测"不符合常识"的写法。核心理念:**现实题材从严,特殊题材按豁免维度放行**。

## 六个常识维度
| 维度 | 检测点 | 例(违常识) |
|------|--------|------------|
| 物理 | 光速/重力/温度/能量守恒 | "一拳打碎山峰但脚下地面没塌" |
| 时空 | 距离/时间/穿越/时差 | "日出前从北京到上海吃晚饭"(除非瞬移设定) |
| 人体 | 生理极限/恢复/失血/睡眠 | "三天三夜不睡还精力充沛" |
| 因果 | 逻辑链/动机/概率 | "路人恰好带解药" |
| 社会 | 法律/经济/阶层/货币 | "古代用手机付账" |
| 历史地理 | 朝代/地名/气候/物产 | "唐代人吃玉米"(玉米明末才传入) |

## 特殊题材豁免规则
| 题材 | 可豁免维度 | 仍须遵守维度 |
|------|-----------|-------------|
| 玄幻/修仙 | 物理(御剑/瞬移/炼丹)、人体(辟谷/寿命) | 因果、社会、时空(相对)、历史地理(架空则全免) |
| 科幻 | 物理(超光速/传送,需自洽) | 因果、逻辑(硬科幻须自洽) |
| 历史架空 | 历史地理(虚构朝代) | 物理、因果、社会(须自洽) |
| 都市/现实 | 全部从严 | 全部 |

## 检测逻辑
1. **确定性规则优先**(免费脚本 `commonsense_check.py`):
   - 时空矛盾:同一章内"瞬移"类词 + 现实题材 → 告警。
   - 物理常数:违反光速/能量守恒的现实描写 → 告警。
   - 因果:无铺垫的巧合("恰好")→ 告警(除非已伏笔)。
2. **LLM 兜底**:题材豁免判断 + 复杂常识(历史地理)用 LLM 判,标注豁免维度。

## 使用
```bash
python3 ~/.claude/skills/plan-plot/scripts/commonsense_check.py <章节.txt> [--genre 玄幻]
```
- 不标 --genre → 默认现实题材(从严)。
- 特殊题材必须显式标,否则按现实误报。
