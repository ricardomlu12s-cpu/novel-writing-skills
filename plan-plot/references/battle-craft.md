# 战斗场景craft(Battle Craft)

打斗描写不能堆砌"天地变色"等空洞形容词。要有**招式拆解/物理打击感/心理攻防/画面感**。男频战斗 = 世界观 + 人物 + 智斗的浓缩呈现。

## 五要素
| 要素 | 含义 | 反例(干瘪) |
|------|------|------------|
| **招式拆解** | 技能/招式的起手→过程→收招,有逻辑 | "他使出一记绝招,天地变色" |
| **物理打击感** | 力量传导/碰撞/地形破坏(符合战力体系) | "一拳轰碎空间" |
| **心理攻防** | 战斗中的判断/诈/读招(智斗在战斗里) | 一招定胜负,无博弈 |
| **画面感** | 镜头语言(慢镜/特写/快切)+ 感官细节 | 全程平铺,无节奏 |
| **代价/消耗** | 战斗有消耗(体力/灵力/受伤),非无代价 | 打完毫发无损 |

## 招式拆解模板
```
起手: 他沉肩屈膝,灵力沿经脉涌向右臂,青筋暴起。
过程: 这一拳带着金石之气,砸向对方护体罡气。接触点迸出裂纹,罡气应声裂开一道缝。
收招: 他收拳后退半步,呼吸微乱——这一击耗去三成灵力。
```
- 招式 = 起手(蓄力)→ 过程(碰撞/属性交锋)→ 收招(消耗/余波)。
- 每招符合战力体系(境界/属性/克制,power-system)。

## 物理打击感
- 力量传导:拳到肉/武器碰撞的**传递感**(不是"轰"一声带过)。
- 地形破坏:符合战力等级(炼体碎石,金丹劈山,但不能"一拳碎星辰"若战力未到)。
- 感官:骨裂声/血味/震麻的虎口/视线晃动。

## 心理攻防(智斗在战斗)
- 战斗是**博弈**:读招/诈招/诱敌/抓住破绽(不是硬碰硬数值碾压)。
- 与 write-mystery 联动:战斗中的判断 = 推理链(线索=对方招式习惯,知识=功法克制)。
- 越级战斗:靠信息差/规则漏洞/环境借势(呼应 power-system 越级规则)。

## 画面感(镜头语言)
- 慢镜:关键一击的细节放大。
- 特写:表情/手势/武器细节。
- 快切:交锋的连续快节奏。
- 感官:声音(呼啸/碰撞)/温度/气压(具体,非"天地变色")。

## 禁空洞词
```python
VOID_BATTLE = ["天地变色", "空间震荡", "山河破碎", "日月无光", "威压盖世", "气吞山河"]
```
命中即告警 → 换具体物理证据(地形/感官/招式)。

## 检查清单(每战斗场景)
1. 招式拆解了吗?(起手/过程/收招)
2. 物理打击感足吗?(传导/地形/感官)
3. 有心理攻防吗?(判断/诈/读招,非数值碾压)
4. 画面感强吗?(镜头/感官)
5. 有消耗/代价吗?(非无代价)
6. 禁空洞词了吗?(天地变色等)
