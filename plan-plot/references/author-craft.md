# 作者常用技法库(分卷/卡文等)

成熟作者的手艺,AI 最容易缺。这是 plan-plot 的"作者技法"能力。

## 1. 分卷规划
长篇小说按卷划分,每卷是独立"可读单元":
- **每卷结构**:卷内三幕(铺垫→推进→小高潮收束)+ 卷末留新钩子(引下卷)。
- **卷间过渡章**:一卷结束到下一卷开头的"换气章",交代时间流逝/地理迁移/心境变化。
- **卷主题**:每卷一个核心命题(如"卷一:崛起""卷二:背叛""卷三:代价"),避免卷卷雷同。
- **卷长**:一般 30-60 章,视题材(网文可短些)。
- **分布**:每卷至少 1 个中高潮收束,大高潮间隔 ≥20 章。

## 2. 卡文处理(破局法)
AI 卡文/写不下去时的处理——**禁止硬推进**:
- **换角度重述**:同一事件换角色视角/换场景/换时间线重述。
- **缩小场景**:把大场面拆成小冲突(一场对话/一个动作),先写小再放大。
- **引入新信息**:新线索/新角色/旧角色反常行为 → 打破僵局。
- **时间跳跃**:跳过无意义的"过渡时间",直接切到关键节点。
- **改配角视角**:主角线卡住时,从配角视角推进同一事件。
- **反推法**:先定本章结尾的钩子,倒推怎么到这结尾。

## 3. 其他技法
- **换地图**:一卷结束换新场景(新环境/新势力)→ 注入新鲜感,但新场景要承接旧伏笔。
- **收束**:支线/伏笔分批回收,不攒到结尾一起爆。
- **张弛**:爽章后必缓冲,虐章后必喘息(与高潮调度呼应)。
- **留白**:关键处不写完(章末钩子/对话切断),让读者脑补。

## 4. 与 quality gate 集成
- 分卷:大纲阶段就定卷结构(喂给 write-chapter plan.md)。
- 卡文:write-chapter 检测到推进困难 → 调用本库破局,而非硬写。
