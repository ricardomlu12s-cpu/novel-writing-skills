# 杀伐果断守卫(Kill-Decisive Guard)

**对抗模型的"正向和平偏见"**:模型底层微调偏于安全/正向 → 倾向化解冲突、洗白反派、劝人向善 → 男频最核心的"杀伐果断"与"打脸爽感"被毁。本守卫强制主角该杀就杀、该打就打。

## 三大偏置 + 守卫
| 模型偏置 | 表现 | 守卫检查 |
|---------|------|---------|
| **化解冲突** | 主角受辱/被算计 → 被劝"算了/冤冤相报何时了" | 该反击时是否反击(按人物+剧情) |
| **洗白反派** | 反派作恶 → 突然"他也有苦衷"被洗白 | 反派洗白是否有充足铺垫(非模型心软) |
| **劝人向善** | 主角觉醒"杀戮不对" → 爽点被道德化截断 | 该打的打了吗(爽点完整) |

## 守卫规则
1. **合理反击**:主角受辱/被算计 → 检查是否按人物性格+剧情合理反击(不被劝"算了")。
   - 主角是杀伐型 → 受辱即反击(果断)。
   - 主角是隐忍型 → 反击有延迟,但**必须最终反击**(不是被劝退)。
2. **反派洗白检测**:反派被洗白 → 查是否有 ≥3 处铺垫(他的苦衷/动机)。无铺垫即"模型心软" → 打回。
3. **爽点完整**:打脸场景 → 检查是否被"化解冲突/原谅反派"截断。该打的没打 → 告警,补完整打脸。
4. **代价约束**(防无脑):杀伐 ≠ 无脑。杀要承担后果(敌人报复/道德挣扎/身份暴露),与战力/常识联动。

## 检查清单(每受辱/打脸/洗白场景)
1. 主角受辱 → 反击了吗?(或按隐忍型有最终反击)
2. 被劝"算了"了吗?(被劝 = 正向偏置,查是否合理)
3. 反派洗白有铺垫吗?(无 = 模型心软)
4. 打脸完整吗?(没被化解截断)
5. 杀伐有代价吗?(非无脑)

## 与现有衔接
- 爽点五阶段(satisfaction-cycle):打脸完整 = 爽点兑现。
- 代价约束(power-system/commonsense):杀要承担后果。
- 男频平台(adapt-platform):番茄版更强调杀伐果断(高频)。
