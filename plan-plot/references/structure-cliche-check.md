# 结构老套检测(Structure Cliche Check)

cliche_detect 只查**已知套路词**(打脸/退婚)。本机制查**整体结构老套**(开局废柴→奇遇→逆袭 这种大框架)。

## 常见老套结构(命中即查新)
| 老套结构 | 特征 | 反例 |
|---------|------|------|
| **废柴逆袭线** | 开局废柴→奇遇→逆袭→登顶(线性) | 无数模板文,无新意 |
| **穿越碾压线** | 穿越→现代知识碾压→开后宫→称霸 | 穿越即无敌 |
| **复仇登顶线** | 开局被灭门→复仇→逐级打脸→登顶 | 目标单一,线性 |
| **苟道发育线** | 谨慎发育→扮猪吃虎→后期无敌 | 全篇苟,无波澜 |

## 结构查新检查
1. **起承转合有新意吗**:开局不是"废柴被辱"(错位开局/倒叙/多线)。
2. **发展有意外吗**:不是"奇遇→变强"线性(有失败/有代价/有反转)。
3. **终点有新意吗**:不是"登顶即终点"(有代价/有升华/有开放)。
4. **结构是单线还是多线**:单线线性最易老套,多线/倒叙/群像更新。

## 结构破局建议
- **错位开局**:不是废柴被辱,而是开局已巅峰→跌落→重来。
- **倒叙/多线**:从结局倒叙,或多线并行(不同人物的命运交织)。
- **反转结构**:以为是逆袭流,中盘发现是陷阱(伪逆袭)。
- **代价结构**:登顶有不可逆代价(不是白拿)。
- **开放式**:终点不圆满,留"意难平"(更高级)。

## 与 cliche_detect 区分
- **cliche_detect**:查已知套路词(打脸/退婚)→ 章节级。
- **本机制**:查整体结构(废柴逆袭/穿越碾压)→ 全书级。
- 两者互补:一个查词,一个查框架。

## 检查清单(开书/大纲阶段)
- [ ] 开局结构有新意吗?(非废柴被辱/穿越碾压)
- [ ] 发展有意外吗?(非奇遇→变强线性)
- [ ] 终点有新意吗?(非登顶即终点)
- [ ] 是单线线性吗?(是=易老套,考虑多线/倒叙)
- [ ] 结构破局了吗?(错位/倒叙/反转/代价)
