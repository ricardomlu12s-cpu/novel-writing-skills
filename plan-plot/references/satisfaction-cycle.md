# 爽点五阶段循环模板

商业网文的本质是"期待感管理"。一个完整的爽点循环由五阶段构成,每章(尤其高潮章)按此设计。

## 五阶段
| 阶段 | 任务 | 技巧 |
|------|------|------|
| 1. 期待铺设 | 展示阶段性高额奖励/秘宝/关键解密,建立获取预期 | 明确"得到了会怎样" |
| 2. 低谷压抑 | 反派施压/环境恶化/资源匮乏,主角表面绝对劣势 | 积蓄情绪势能 |
| 3. 转折爆点 | 主角亮隐藏底牌/技术突破/出人意料逆袭方案 | 信息差制造意外 |
| 4. 降维打击 | 情绪瞬间释放,碾压式解决危机,兑现前文期待 | 短句+动作,利落 |
| 5. 余波反馈 | 旁观者震惊/敌人悔恨/权威认可,多角度正向确认;顺势抛下个钩子 | 无缝衔接下一循环 |

## 循环检测
- 某章从"低谷"直接跳"胜利"无"转折爆点" → 爽点不成立(靠意志力爆种,违例)。
- 无"余波反馈" → 爽感未确认,读者爽不到。
- 连续多章无完整循环 → 节奏乏力,建议插入一个小循环。

## 与黄金三章衔接
- 第三章的"首次爆杀"= 第一个完整五阶段循环。

## 与 anti-resolution 衔接
- 非终局章禁止"彻底解决"主线冲突;循环内的"胜利"是阶段性的,须留新钩子。
