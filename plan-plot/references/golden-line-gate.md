# 金句守门(Golden Line Gate)

金句的排布**以男频神作/白金作家为对照依据**,不是"高潮才出"的单一规则,也不许"每章硬凑"。

## 核心认知(对照白金)
- 金句 = **记忆符号/作品签名**,极少而精,由**情绪峰值自然爆出**——不是造出来的,是长出来的。
- 不只能高潮触发:开篇/轻描淡写/别有用心处(配角高光、闲笔藏锋)都可出。

## 五类金句(每类配神作实证 + 触发条件)

| 类型 | 神作/白金实证 | 触发条件 | 特征 |
|------|-------------|---------|------|
| **黄金一句**(开篇) | 《斗破》"斗之力,三段!"(肘子"黄金一句"论);辰东视觉锤开篇 | 第一章前 100 字,立反差/期待 | 一句话立住全书卖点 |
| **母题反复**(信念句) | "等我回来"→站台/病房/墓碑(丈量时光的尺);《斗破》"莫欺少年穷"当作品符号 | 关键时刻重复,承载成长 | 同一句不同时刻,味不同 |
| **冷笔触**(轻描淡写) | "庭有枇杷树,吾妻死之年所手植也,今已亭亭如盖矣"(无一字写思念) | 情绪顶点用克制记录反衬 | 越收敛,情绪越汹涌 |
| **留白/话留半句** | "当年要不是你爸……"(戛然而止);猫腻东方式克制 | 关键处不说完,沉默来补 | 没说完的话更让人在意 |
| **爆点金句**(高潮) | 猫腻"看对方怎么输"而非"自己赢";情绪峰值自然爆出 | 张力≥7 时回扣前文 | 从情节里长出来,有语境 |

## 别有用心处(用户强调,对照神作)
- **配角高光**:让配角装逼(李淳罡封神——《雪中》)——金句不必都在主角口中。
- **闲笔藏锋**:烽火"闲笔=高级伏笔"——把反转藏在废话里。
- **轻描淡写**:冷笔触可在非高潮处,一句轻话反衬浓烈。
- **大俗话**:白金也用俗话做金句(大俗即大雅),不必华丽。

## 含金量检查(对照白金,四问)
1. **配得上**:金句回扣前文具体事件/意象吗?(有语境,非空洞万能)
2. **删了变淡吗**:删掉这句,场景是否变淡?不变淡 → 假金句,删。
3. **能共鸣吗**:有真实洞察吗?(不是"或许这才是人生"式空话)
4. **密度克制吗**:母题反复 3-4 次封顶;哲理型金句每 20 章 ≤1 个。

## 金句与去AI味的关系
- 金句是"正向打磨",去AI味是"反向清除"——两者互补。
- AI 专属表达(空气仿佛凝固/这一夜他明白了)是**假金句**,直接清除,不进金句池。

## 使用(集成质量门)
- 每章质量门:金句出现 → 按五类分型 → 过含金量四问 → 不过则删/改。
- 金句登记:命中且过审的金句写入 `<项目目录>/golden-lines.jsonl`(类型/章节/原文),母题反复靠登记查重。
