# 反转与伏笔:认知误导与因果逆向追溯(Retroactive Inevitability)

利用读者心理盲区建立预期,再通过前期隐藏的因果链在爆发期颠覆。**防"机械降神(Deus Ex Machina)"**。

## 反转三原则
1. **意料之外**:读者没想到(AI 常见错误:太可预测)。
2. **情理之中**:回头看完全合理(必须有前期因果链)。
3. **因果逆向追溯**:反转后读者能回想到伏笔("原来那时候就有")。

## 机械降神检测(禁止)
AI 最常犯的机械降神,命中即告警:
| 机械降神 | 例 | 为什么坏 |
|---------|-----|---------|
| **凭空幕后黑手** | 结尾突然冒出没人提过的最终反派 | 无伏笔,颠覆无依据 |
| **突然复活** | 死了的角色莫名复活 | 无代价,无伏笔 |
| **突然失忆/恢复记忆** | 为剧情硬给记忆开关 | 机械,非因果 |
| **凭空金手指解局** | 绝境突然天降神助 | 无前置铺垫 |

## "意料之外情理之中"验证
- 反转出现后,检查:前期是否有**至少 2 处伏笔/铺垫**(1 处自然融入 + 1 处侧面强化,呼应伏笔三级递现)。
- 无伏笔 → 告警"机械降神",需补前置铺垫或改写。
- 有伏笔 → 验证"回看合理",读者能想起"原来那时候就有"。

## 认知误导手法
- **预期引导**:先让读者以为 A → 再反转。
- **隐藏因果链**:关键伏笔埋在"不起眼处"(三级递现的一级:自然融入)。
- **误导 + 翻盘**:误导读者判断方向,爆点翻盘。

## 检查清单(每个反转)
1. 前期有 ≥2 处伏笔/铺垫吗?(无 → 机械降神告警)
2. 反转是"意料之外"吗?(太可预测 → 无惊喜)
3. 反转后"情理之中"吗?(回看能想到伏笔)
4. 无凭空解局/复活/失忆吗?
