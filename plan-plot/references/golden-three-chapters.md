# 黄金三章专项约束

作品前三章是"生死线",决定读者是否留存。AI 写作时必须严格执行。

## 三章硬约束
| 章 | 硬约束 | 禁止 |
|----|--------|------|
| **第一章(起)** | 极速切入核心生存危机;展示主角独特潜质或金手指预告 | 严禁大段世界观设定铺陈(Infodump) |
| **第二章(承)** | 矛盾升级,对手加压,主角获取关键筹码 | 严禁平淡过渡 |
| **第三章(转/合)** | 绝地反击,完成首个高潮爆杀,铺设次级新悬念 | 严禁把高潮拖到更后 |

## 三章节奏模板
```
第一章:危机 → 潜质/金手指预告 → 章末钩子(生死悬念)
第二章:压抑蓄力 → 对手嚣张 → 主角冷静布局 → 关键筹码
第三章:爆发 → 首次爆杀 → 余波 → 次级新悬念
```

## 检测
- 第一章文本含 >20% 世界观说明 → 违例,打回重写。
- 第三章无高潮爆发 → 违例,爽点节奏未达标。
- 三章均无章末钩子 → 违例。

## 与 quality gate 集成
- write-chapter 写前三章时强制走本约束,黄金三章不达标不进后续。

## 衔接
- 爽点五阶段循环(`satisfaction-cycle.md`)为第三章的爆杀提供结构。
- 取名学(`naming-craft.md`)让书名在三章前就锁定卖点。
