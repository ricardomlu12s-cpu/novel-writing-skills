# 剧情因果动能(Causal Kinetic Plotting)

把情节从"然后……然后……(And then)"升级为"因此/但是(Therefore/But)"。防流水账与平淡过渡。

## 每场戏 5 硬指标(缺一即"平淡过渡章",须拦截)
| # | 硬指标 | 含义 | 反例(流水账) |
|---|--------|------|--------------|
| 1 | **推动目标** | 主角朝当前目标前进/后退一步 | 这场戏什么都没推进 |
| 2 | **增加阻碍** | 新增障碍/成本/反派对压 | 一帆风顺无冲突 |
| 3 | **暴露新信息** | 揭示新线索/真相碎片/角色秘密 | 无新信息,重复已知 |
| 4 | **改变关系** | 人物关系/阵营有变动 | 关系无变化 |
| 5 | **不可逆后果** | 事件造成不可撤销的后果(代价/损失) | 可以当作没发生过 |

## 因此/但是 检查
- **"因此"**:A 事件 → 因果 → B 事件(不是并列)。
- **"但是"**:计划 → 意外 → 转折(不是顺理成章)。
- 每场戏结束问:这场戏有"因此/但是"吗?还是"然后"式并列?

## 防巧合与硬推
- 禁止:无铺垫的巧合(路人恰好带解药)——除非已伏笔(呼应 commonsense 因果维度)。
- 禁止:硬推(为了剧情让角色突然降智/性格反转)——呼应 psychodynamic 行动化检查。

## 检查清单(每场戏)
1. 5 硬指标命中几个?(<3 即流水账,打回)
2. 事件链是"因此/但是"还是"然后"?
3. 有巧合/硬推吗?(有 → 补伏笔或改写)

## 历史惯性(Historical Inertia,防"改一个小因就掀翻整个大事件")

**问题**:重大事件往往由**多个独立原因**共同造成。只改变其中一个小因素,不该让整个事件凭空消失——否则会"蝴蝶效应廉价化"(改一点就天翻地覆)。

- **多因归因**:大事件列出它的全部成因(如:龙类苏醒 + 组织决策 + 某 NPC 行动 + 政治利益 + 地点异常)。
- **改变单个因素** → 事件通常只是:延后 / 改变参与人 / 改变地点 / 改变方式 / 改变结果(而非消失)。
- **只有关键因果链被真正破坏** → 事件才 PREVENTED 或 INVALIDATED(永久不发生)。
- **禁止用"命运自动修正"** 解释作者想强行走回原剧情——历史惯性是"多因的客观结果",不是"命运强制力"。

**与蝴蝶效应账本联动**:每次"改一个小因"→ 记入 butterfly-ledger,标"只改变了 X 因素,大事件整体仍会以 Y 方式发生(或延后/换人)",而非直接标"事件被阻止"。
