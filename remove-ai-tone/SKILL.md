# De-AI-Slop — 中文叙事去AI味

把"有AI味"的中文小说改回"像人写的"。核心理念:**不是删词,是用具体细节替代抽象套话、用行动替代状态描述**。方法论基于 [humanizer skill](https://github.com/blader/humanizer) + novel-creator-skill 的中文定制。

## 0. 判断脚本(确定性检测,先跑,零成本)
```bash
# 多语言: 自动识别(中文/英文),或 --locale 指定
python3 ~/.claude/skills/remove-ai-tone/scripts/detect_aislop.py <文件.txt>
python3 ~/.claude/skills/remove-ai-tone/scripts/detect_aislop.py <文件.txt> --locale en
python3 ~/.claude/skills/remove-ai-tone/scripts/detect_aislop.py --list-locales
```
输出命中模式清单与行号。检测不到/不显著 → 无需大改;命中多 → 逐段改写。

**多语言**: 词表外置在 `locale/<语言>.json`。中文/英文已内置完整词表;日/俄是空模板(仅结构检测);母语者可贡献新语言词表(见 `CONTRIBUTING-locales.md`)。方法论(7 类模式/两遍式/反净化)语言无关,词表按语言可插拔。

## 0.4 机器化表达量化检测(词汇贫乏/句式单调)
```bash
python3 ~/.claude/skills/remove-ai-tone/scripts/machinese_detect.py <文件.txt>
```
按语言学研究数据量化(对照人类基线):
- **词汇丰富度 TTR**(<0.40 贫乏,人类~0.50+)
- **句式变化 SVR**(<3 单调,机器仅人类68%)
- **转场词密度**(>14/千字 过度,AI高31%)
- **模板化段落**(>50% 模板化,AI基线80%)
- **表层情绪词**(>3/千字 浮于表面)
命中 ≥2 项 → 建议改写。**情感深度**见 `references/emotion-depth-check.md`(表层词→行动呈现/共同经验/情境智能)。

## 0.5 中文标点规范化(发表前必跑)
```bash
# 单文件
python3 ~/.claude/skills/remove-ai-tone/scripts/normalize_punct.py <文件> --inplace
# 一键全扫全书正文+草稿(防遗漏)
python3 ~/.claude/skills/remove-ai-tone/scripts/normalize_punct.py <项目目录> --all
```
- **规范**:全角标点 `，。；：！？（）` + 规范引号 `“”`。
- 修复:半角 `,;:!?()` → 全角;`「」` → `“”`;ASCII `"` → `“”`。
- **目录 --all 模式**自动扫 `manuscripts/` + `drafts/` 全部 md,防漏(教训:以前只扫眼前几个漏了 ch005)。
- **发表前必跑**(起点/番茄/阅读器对半角/非规范引号不友好)。

## 0.6 引号/标点规范校验(每章定稿前强制,GB/T 15834—2011)
```bash
# 单文件
python3 ~/.claude/skills/remove-ai-tone/scripts/check_punct_spec.py <文件>
# 全卷
python3 ~/.claude/skills/remove-ai-tone/scripts/check_punct_spec.py <项目目录> --all
# 发布目录(嵌套结构,发布/卷一/xxx.txt → 必须 --all 递归)
python3 ~/.claude/skills/remove-ai-tone/scripts/check_punct_spec.py <发布目录> --all
```
- **查出**:双引号/单引号左右不平衡、双引号内嵌套双引号(应为外双内单)、独立对话误用单引号、ASCII 引号残留、半角逗号混用、省略号用 `...` 而非 `……`。
- **递归**:`--all` 用 `**/*` 递归扫全部 md/txt;**非递归扫目录**若无直接文件(如发布目录)会提示"有子目录,加 --all",不再误报"无文件"。
- **强制**:每章定稿前必跑;有错→打回修,修完复检通过才进 manuscripts。
- **注意**:normalize_punct 只修 ASCII/「」→“”,**不查嵌套规范**;本脚本补上(教训:以前只靠 normalize,漏了嵌套/漏配)。

### 引号规范速查(GB/T 15834—2011)
- **双引号** “ ”(左=前引号,右=后引号);**单引号** ‘ ’。
- **嵌套**:外层双引号,内层单引号(`他说:“他管那东西叫‘债’。”`)。
- **独立对话**用双引号,不用单引号。
- ASCII `"` `'` → 一律中文引号;前引号不在行末、后引号不在行首。
- 并列引号间不用顿号;省略号用 `……`、破折号用 `——`。

## 1. 两遍式润色(强制)
**第零步:定文体** — 这段是动作/对话/心理/抒情/说明哪类?按文体定改写强度(见 `references/style-target-and-intensity.md`):动作/对话高,心理中高,抒情中,说明低。
**第一遍:清除 AI 模式** — 逐段扫描 7 类模式处理(见下),只改该文体对应的重灾区。
**第二遍:AI 自审** — 对自己的修改稿提问:
> "这段哪里还是明显 AI 生成的感觉?"列出 3-5 条 → 针对再改。

**方向校准**: 改完对目标风格库指纹(如"龙族江南文风"短句15-18/省略号留白)确认不脱风格——是"往目标文风改",不是"往中性人话改"。

## 2. 七大 AI 写作模式(逐段扫描)
完整特征清单见 `references/ai-slop-patterns.md`。概览:

| # | 模式 | 例 → 改法 |
|---|------|-----------|
| 1 | **AI高频词** | ~~他不禁感到一阵心悸~~ → 他的手抖了一下 |
| 2 | **弱化副词泛滥** | ~~他微微点了点头~~ → 他点了点头 |
| 3 | **意义膨胀** | ~~这次会面意义深远~~ → 从那以后,他改变了用兵的方式 |
| 4 | **通用结论套话** | ~~展望未来,他充满希望~~ → 他把信折好,放进了锁匣 |
| 5 | **论文式段落** | ~~不难看出,他已下定决心…~~ → 他走向了马厩,没有回头 |
| 6 | **正式语体入侵** | 小说里冒出公文/学术腔 → 拉回口语/叙事语体 |
| 7 | **排比三连过多** | ~~勇气、智慧和决断力~~ → 他很果断 |

## 2.5 AI 专属表达(身份指纹,最高优先级)
**人类再有才华的作者也不会写这些**——一旦出现即"非人感"。清单见 `references/ai-only-fingerprint.md`:
- 万能意象:空气仿佛凝固 / 时间在这一刻静止 / 扑面而来
- 过度递进:不仅仅…更是… / 不只是…而是…
- 拟人过度:…仿佛在诉说着…
- 哲理收尾:这一夜他明白了 / 或许这才是…的真谛
- 抽象修饰:以一种…的姿态 / 无声的…
- 逻辑机械感:每个伏笔完美对称 / 每章都升华

**检测**:`detect_aislop.py` 的 `AI_ONLY` 层,命中即严重告警(身份指纹,最高优先级)。改写原则:删模板句 → 写具体物理证据/动作,不追求"完美表达"。

## 2.6 非人感结构扫描(超越字词,最高优先级)
**字词黑名单只抓已知;结构扫描抓"人类不会这样写"的统计特征**。方案见 `references/non-human-structure.md`:
- **句法模板**(正则抓结构,非词):递进句式/修饰模板/万能意象/拟人过度/哲理收尾。
- **分布异常**:句长方差低(<3→AI腔)/升华率过高(>40%→机械)。
- **堆叠 vs 点缀**:单次命中=不算(可能是玩梗);一段 3+ 次同类=堆叠告警。
- **豁免区**:用户说"加进梗库" → `.omc/style-library/<项目>/deliberate-expressions.jsonl` → 命中即跳过(保护玩梗/谐音/抽象自由)。
```bash
python3 ~/.claude/skills/remove-ai-tone/scripts/non_human_scan.py <章节.txt> [--exempt <豁免区.jsonl>]
```

## 3. 有灵魂的写作 vs 干净但无灵魂
避免 AI 模式但仍然无聊 = 写作失败。好的写作有:**具体细节、行动驱动、声音独特、意外与摩擦**。润色后若无灵魂,继续"具体化 + 行动化 + 加杂质(怀疑/犹豫/杂乱)"。

## 4. 与 learn-style 协作(防误伤)
- learn-style 的**风格指纹**可辅助判断"哪些是作者的刻意风格,哪些是 AI 味"——刻意风格(如大量省略号是该作者特色)不算 AI 味,不误改。

## 4.5 三层禁用词 + 格式控制 + 反净化(三个独立 reference,勿遗漏)

- **三层禁用词**:见 `references/forbidden-words.md`(公开禁词 / 项目禁词 / 弃用句三级),写作前 grep 防误用(例:某同人项目的「豁然开朗」弃用句)。
- **格式控制**:见 `references/format-control.md`(长短段交错/节奏留白/排版比例,按题材定对白·描写·心理配比)。这是**去AI味的格式层面**,不是发布整页排版——整页排版归 publish-book。
- **反净化 / 反正向偏置**:见 `references/anti-sanitization.md`。模型会无意识把一切正向化、洗白化、健康绿色化(该打的仗被"算了"、反派被洗白、脏话/暴力/情欲/阴暗被和谐)。**该脏就脏、该狠就狠、该暗就暗,但每一处要有"人物为什么这样"的因果**。检测信号已进 `detect_aislop.py`(反净化-* 三类,命中须 LLM 兜底核对是否有铺垫)。

## 5. 门禁集成(write-chapter)
- 每章草稿 → remove-ai-tone 审查 → **通过才进定稿**。
- 命中严重(如整段套话) → 打回重写,不让 AI 味进正典。
- **信号接进化(evolve-style)**:漂移/AI味检测命中率超阈值(连续 2 章高)→ 触发进化引擎小学习 + 指纹核对;与防固化(rigidity_scan)共用"限用令"工具(AI 味要清,模仿固化要防,两者同源工具)。

## 喂给谁 / handoff
- **write-chapter**:每章定稿前去AI味审查。
- **learn-style**:风格指纹供区分刻意风格 vs AI 味。
- **build-world 面板**:润色状态可显示。
- 产物:改写稿 + 命中清单(detect 脚本输出)。
