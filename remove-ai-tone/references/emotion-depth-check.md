# 情感深度检测(Emotion Depth Check)

**情感连结缺失**:浮于表面的情绪描述、缺乏共同经验、情境智能不足。本机制让情绪"有层次、能共鸣、合情境",不只用表层情绪词。

## 三层情绪(检测 + 改写)
| 层 | 表现 | 例 |
|----|------|-----|
| **表层情绪词**(浮) | 直接说"高兴/悲伤/愤怒" | "他很悲伤" |
| **具体行动呈现**(有层次) | 用行动/生理/环境表达情绪 | "他把那封信折好,放进锁匣,没有哭" |
| **复杂情感层次**(深度) | 情绪叠加/矛盾/潜台词 | "她在笑,但握杯子的指节发白" |

## 检测:表层情绪词密度(机器化表达)
- 大量"高兴/悲伤/愤怒/开心/难过"直接出现 → 浮于表面(见 machinese_detect.py 第 5 项)。
- **改写**:表层词 → 行动/生理/环境呈现(Show, Don't Tell,呼应 remove-ai-tone"具体化")。

## 共同经验(让读者认同)
- **缺失**:AI 无法真实引用生活体验 → 内容无认同感。
- **检测**:是否有人类共同经验的具体载体(童年记忆/亲人告别/失眠/错过/遗憾)?
- **改写**:加"人类共通体验"的具体场景(如:离家的早晨/亲人的一句"好好吃饭")——呼应龙族"婶婶说好好吃饭"那种共鸣。

## 情境智能(文化/背景细微差异)
- **缺失**:AI 难以理解特定文化背景的情感细微差异 → 表达生硬。
- **检测**:情绪是否贴合人物的文化/时代/身份?(古代 vs 现代、东方克制 vs 西方直白、少年 vs 中年)
- **改写**:按人物的文化坐标校准情绪表达(东方克制用留白,西方可用直白;少年笨拙,中年克制)。

## 与现有衔接
- **remove-ai-tone"具体化+行动化"**:表层词改行动呈现。
- **golden-line(金句守门)**:复杂情感层次常是金句的来源(冷笔触/留白)。
- **write-romance(感情线)**:情感层次是感情戏真实性的基础(明暗线/潜台词)。
- **style-fingerprint(风格)**:情感浓度/克制是风格指纹的一维。

## 检查清单(每情感场景)
- [ ] 表层情绪词用了吗?(高兴/悲伤… → 改用行动呈现)
- [ ] 有共同经验载体吗?(让读者认同)
- [ ] 情绪贴合人物文化/时代/身份吗?(情境智能)
- [ ] 有复杂情感层次吗?(叠加/矛盾/潜台词,非单层)
