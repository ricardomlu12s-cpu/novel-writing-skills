# AI 专属表达(AI-Only Fingerprint)

**人类再有才华的作者也不会写出这些表达**——它们是 AI 的"身份指纹"。一旦出现,立刻"非人感"。与"AI 高频词"(人类也用只是用多)不同,这些是**人类根本不用**的。

## 一、句法层(万能意象 / 模板句式)

| 表达 | 为什么是 AI 专属 | 人类写法替代 |
|------|-----------------|-------------|
| 空气仿佛凝固了 | 被 AI 用烂的万能"紧张"意象 | 写具体:杯中的水纹停止了晃动 |
| 时间仿佛在这一刻静止 | 万能"重要时刻"意象 | 写具体:他数着心跳,一、二、三 |
| 一股…的气息扑面而来 | 万能"登场/氛围"模板 | 写具体:风里混着铁锈和汗味 |
| 不仅仅…更是… | 过度递进模板,每段可用 | 直接陈述,不用递进包装 |
| 不只是…而是… | 同上 | 删掉,直说 |
| …仿佛在诉说着… | 拟人化过度(万物都在诉说) | 写物本身的状态 |
| 以一种…的姿态/方式 | 抽象修饰,空洞 | 写具体动作 |
| 无声的…(叹息/泪/呐喊) | 过度"无声"渲染 | 写声音或动作本身 |
| 这一夜,他明白了… | 哲理式收尾模板 | 写行动,不写总结 |
| 或许,这才是…的真谛 | 万能升华结尾 | 删,留给读者体会 |

## 二、语义/逻辑层(机械的"太完美")

| 模式 | 为什么是 AI 专属 | 人类写法 |
|------|-----------------|---------|
| 每个伏笔都完美对称回收 | 现实人生/好小说都有留白与失效 | 允许 1-2 个伏笔自然消失/转义 |
| 每章结尾都升华总结 | 人类作者经常平实收尾 | 有的章就是"事情发生了" |
| 每个角色说话都带潜台词 | 太完美,失真 | 允许角色有时直白/有时废话 |
| 情感过渡毫无突兀 | 太顺滑,机械 | 允许情绪断层/突转 |
| 过度用"一切/终究/毕竟/始终" | 因果解释过密 | 少解释,多呈现 |
| 三连排比后必接升华句 | 结构完美到假 | 排比后接具体行动,不升华 |

## 三、检测信号(确定性优先)
```python
AI_ONLY = [
    "空气仿佛凝固", "时间仿佛", "在这一刻静止", "扑面而来",
    "不仅仅", "不只是", "更是", "仿佛在诉说", "无声的",
    "这一夜，他明白", "的真谛", "以一种", "终究还是",
    "一切尽在", "仿佛天地", "万物静默",
]
```

## 与现有层区别
| 层 | 检测什么 | 人类会写吗 |
|----|---------|-----------|
| 7类AI模式 | 不禁/微微/嘴角微扬 | 会(只是用多) |
| 公文技术词 | 张力/闭环/赋能 | 不用于小说(借用) |
| **AI专属表达** | 空气凝固/不仅仅是/这一夜他明白 | **根本不会写** |

## 使用
- `detect_aislop.py` 加 `AI_ONLY` 层,命中即**严重告警**(身份指纹,最高优先级)。
- 改写原则:删除模板句 → 写**具体物理证据/动作**,不追求"完美表达"。
