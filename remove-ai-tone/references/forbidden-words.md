# 三层负面禁用词清单(中文叙事)

报告强调:AI 高频调用公文/技术色彩抽象词,使小说脱离文学语境。三层负面词表 + 替换建议。

## 第一层:见即删(直接替换)
公文/技术腔,出现在小说里即违例:
| 词 | 问题 | 替换 |
|----|------|------|
| 张力 | 文评术语混进叙事 | 写具体:空气凝固、呼吸变慢 |
| 底座 | 技术词 | 写根基/基石(慎)或删 |
| 闭环 | 技术词 | 删,写"收了尾/兜了圈" |
| 赋能 | 技术词 | 删,写"让...更有力" |
| 稳了 | 网络/技术口癖 | 写具体确认动作 |
| 楔子 | 结构术语(非卷首序) | 卷首用"引子/序章"或直接正文 |

## 第二层:成簇可疑(每段 3+ 即处理)
写作/商业泛词,偶尔可用但成簇即 AI 味:
- 逻辑、体系、机制、层面、维度、抓手、颗粒度、方法论、底层逻辑、结构化、闭环思维

## 第三层:零信息填充短语(整删)
```text
值得注意的 / 需要注意的是 / 不然而 / 显而易见 / 综上 / 不难看出 / 换句话说 / 更进一步说
```
## 检测脚本
`remove-ai-tone/scripts/detect_aislop.py` 已含大部分;第一层词表并入其 `AI_WORDS`。

## 原则
- **替换为具象**:抽象词 → 物理证据(感官细节/动作/环境交互)。
- **文学语境**:小说文本不得出现文评/技术/公文术语。
- 与 learn-style 风格指纹协作:若某词是该作者**刻意风格**,不误伤。
