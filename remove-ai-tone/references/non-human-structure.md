# 非人感结构检测(Non-Human Structure Detection)

**超越字词黑名单**:检测"人类不会这样写"的**结构特征**(分布异常),而非具体词。字词限制只抓已知,结构检测抓本质。

## 为什么结构检测更本质
| 黑名单局限 | 结构检测解法 |
|-----------|-------------|
| 只抓已知词 | 抓**句法模板**(正则抓结构,非词) |
| 抓不到组合变化 | 抓**分布特征**(统计) |
| 抓不到"太完美" | 抓**完美对称率/升华率** |

## 一、句法模板检测(正则抓结构,非词表)
| 模板 | 正则示例 | 说明 |
|------|---------|------|
| 递进句式 | `(不仅仅|不只是|不仅)\S{0,12}(更是|而是|而且)` | 结构,非"不仅"一词 |
| 修饰模板 | `以一种\S{0,8}(姿态|方式)` | 抽象修饰结构 |
| 万能意象 | `(仿佛|时间)\S{0,8}(凝固|静止|停滞)` | 意象结构 |
| 拟人过度 | `\S{2,6}仿佛在诉说着?` | 万物诉说话 |
| 哲理收尾 | `(这一夜|那一刻|或许)，?\S{0,8}(明白|真谛)` | 升华结构 |
| 排比三连 | 已存在(TRIPLE_RE) | 顿号三连 |

## 二、分布异常检测(统计,免费)
| 指标 | 检测 | 非人阈值 |
|------|------|---------|
| **句长方差** | 句长分布的标准差 | <3 → 句句均匀,AI 腔 |
| **升华率** | 结尾总结升华段落比例 | >40% → 每章升华,机械 |
| **完美对称率** | 伏笔回收比例(需读 foreshadowing.jsonl) | >95% → 无留白,机械 |
| **模板密度** | 每千字模板命中数 | >8 → 模板堆叠 |
| **修辞密度** | 比喻/拟人/排比占比 | 过高 → 华丽到失真 |

## 三、堆叠 vs 点缀(密度阈值——保护玩梗)
| 场景 | 判定 |
|------|------|
| 单次命中 | **不算**(可能是玩梗/刻意) |
| 一段内 3+ 次同类模板 | 堆叠 → 告警 |
| 连续段落都命中 | 堆叠 → 告警 |
| 用户声明过的梗/谐音/抽象 | **豁免**(跳过) |

## 四、风格豁免区(保护刻意表达)
- 用户说"把这些加进我的梗库" → 进 `.omc/style-library/<项目>/deliberate-expressions.jsonl`。
- 命中豁免区 → 跳过检测(用户声明的就是他的风格)。
- 豁免区示例:
```jsonl
{"expr":"绷不住了","type":"梗","note":"用户口头禅"}
{"expr":"蕉绿","type":"谐音","note":"焦虑谐音"}
{"expr":"抽象","type":"抽象表达","note":"用户刻意玩抽象"}
```

## 五、LLM 兜底
复杂"非人感"用 LLM 判"这句人类作者会不会写"——但给判断标准 + 尊重豁免区,避免 LLM 自己也出 AI 腔。

## 使用
```bash
python3 ~/.claude/skills/remove-ai-tone/scripts/non_human_scan.py <章节.txt> [--exempt <豁免区.jsonl>]
```
- 命中豁免区 → 跳过。
- 密度 < 阈值 → 不算。
- 高密模板堆叠 + 不在豁免区 → 告警。
