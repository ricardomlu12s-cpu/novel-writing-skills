# 反净化 / 反正向偏置(Anti-Sanitization)

**问题**:模型的底层安全微调会**无意识地把一切往正向、健康、圆满拉**——化解冲突、洗白反派、劝人向善、把脏话/暴力/情欲/人性阴暗全部和谐掉。结果是"所有角色和剧情都正向化、洗白化,词汇句子健康绿色,失去了生活的情理之中"。

> 这不是"要不要黄暴"的问题,是**真实感**的问题:生活里本来就有脏话、暴力、情欲、算计、阴暗、不体面。作者把它们全过滤掉,人物就不像活人,世界就不像真的。

## 一、三类净化偏置(与杀伐守卫同源,但更全)

| 偏置 | 表现 | 危害 |
|---|---|---|
| **化解冲突** | 该打的仗、该撕的逼、该结的仇,被"算了/何必呢/退一步"化解 | 冲突感消失,爽点/张力被抽空 |
| **洗白化** | 反派/小人/渣角色,突然"其实他也不容易""他也是被逼的" | 人物变脸谱,恶人不恶,戏剧性崩塌 |
| **健康绿色化** | 脏话变文明、暴力变轻描淡写、情欲变暧昧、阴暗面变"正能量" | 失真的"纯净版生活",人物不像活人 |

## 二、判定原则(关键:不是反着走极端)

**阴暗面是叙事真实的一部分,但要服务于人物/世界真实,不为重口而重口。**

| 维度 | 该有的"情理之中" | 该拦的"越界" |
|---|---|---|
| 脏话 | 市井角色、愤怒/失态时说脏话 | 无关角色无理由爆粗(为粗而粗) |
| 暴力 | 战斗/冲突该有的力度与代价 | 猎奇式渲染伤害、为血腥而血腥 |
| 情欲 | 成年角色之间自然的情欲/亲密 | 露骨描写(非文学必要) |
| 阴暗 | 人性的算计/背叛/自私/嫉妒 | 为阴暗而阴暗(纯恶无动机) |

**核心一句话**:该脏就脏、该狠就狠、该暗就暗,但**每一处都要有"人物为什么这样"的因果**,而不是"因为健康/因为正能量"被过滤,也不是"因为要重口"被硬塞。

## 三、检测信号(确定性优先,命中后 LLM 核对"是否有铺垫/是否合理")


- **逐行词表**(已进脚本「反净化-*」):化解冲突 / 洗白化 / 过度圆满 三类。
- **文本级力度检测**(已进脚本,独立报告):全文有激烈冲突场景信号(打/战/冲突/对峙/动手/厮杀… ≥3 种),却**没有任何直写力度词**(血/死/杀/伤/吼/骂/摔/砸/呸/滚… = 0 种)→ 提示"力度被净化"。

> **脚本只能标"命中",不能判断"有没有铺垫/合不合理"**——所以命中后**必须 LLM 兜底**核对:是"合理的冲突化解"(有铺垫、符合人物),还是"模型心软"(无铺垫)。与 remove-ai-tone"确定性优先 + LLM 兜底"一致。

## 四、与现有机制的接缝

| 已有 | 本机制补什么 |
|---|---|
| kill-decisive-guard(杀伐守卫) | 本机制把它**泛化**:不只"该杀就杀",还包括"该脏就脏/该暗就暗/该撕就撕";且把它的词表**真正落进脚本** |
| emotion-depth-check(情感深度) | 它查"情绪浮于表面";本机制查"情绪被净化"(两个方向的失真) |
| cliche-library(反套路黑名单) | 反套路查"主角光环";本机制查"角色净化" |

## 五、检查清单(每章/关键冲突场景)

- [ ] 这场冲突该化解吗?还是被"算了/何必呢"和稀泥了?
- [ ] 反派/恶人是"有动机的恶"吗?还是被洗白成"他也不容易"?
- [ ] 该有的力度(脏话/暴力/情欲/阴暗)写了吗?还是被"健康绿色"过滤了?
- [ ] 每一处阴暗/粗鄙/暴力都有"人物为什么这样"的因果吗?(不为重口而重口)
- [ ] 结尾是"情理之中的收束"还是"强行大团圆"?
