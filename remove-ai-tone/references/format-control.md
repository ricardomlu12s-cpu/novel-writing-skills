# 格式细粒度控制(Format Control)

AI 输出**段落死板均匀**(每段一样长/节奏无起伏)。要有**长短段交错/节奏留白/排版控制**。

## 三控制
| 控制 | 含义 | AI 通病 |
|------|------|---------|
| **段落长度** | 长短段交错(紧张用短段,舒缓用长段) | 每段 80-120 字均匀 |
| **节奏留白** | 关键处留白/断句(配合金句留白) | 全程填满,无呼吸 |
| **排版比例** | 对话/描写/心理的比例控制(按题材) | 对话过长/描写过多失衡 |

## 段落长度规则
- **紧张场景**:短段(1-3 句/段),窒息感。
- **舒缓场景**:长段(5-8 句/段),从容感。
- **禁均匀**:连续 3 段长度接近 → 告警,打散长短。
- 与高潮调度联动:张力值高 → 短段多;张力低 → 长段多。

## 节奏留白
- 关键转折/情绪顶点后:留白(空行/短句/断句),让读者消化。
- 配合金句守门:金句后留白(独立成段/断行),增加冲击。
- 禁全程填满:每个场景留 1-2 处"呼吸点"。

## 排版比例(按题材)
- 玄幻/战斗:描写+对话为主,心理适中。
- 都市/感情:对话+心理为主,描写点缀。
- 悬疑/智斗:心理+线索呈现为主。
- 与 genre-style-matrix 联动(题材→比例基线)。

## 检测信号
```python
# 均匀段落(连续 3 段长度差 <15%)
# 无留白(全文无独立短段/空行呼吸)
# 比例失衡(对话 >70% 或 <20%)
```

## 检查清单(每章)
1. 长短段交错了吗?(无均匀堆砌)
2. 有节奏留白吗?(关键处呼吸)
3. 排版比例符合题材吗?
4. 金句留白了吗?

## 标点与引号规范(GB/T 15834—2011,2026-08-04 补充)

> 用户指出引号使用不规范(上/下引号不分)。以下为强制规范,每章定稿前核对。

### 引号形式(横排)
- **双引号**:“ ”(左=前引号/上引号,右=后引号/下引号)
- **单引号**:“ ”→ 应为 ‘ ’(左/右)
- ASCII `"` `'` → 一律转中文引号
- 前引号不在行末,后引号不在行首

### 嵌套规则(核心)
- 引号内需再用引号:**外层双引号,内层单引号**(GB/T 4.8.3.4)
- 例:昂热说:“他管那种东西,叫‘债’。”
- 例:他问:“老师,你说‘还债的人’是什么意思?”
- **禁止**:双引号内再用双引号(`“他叫“债””` 是错的)

### 双引号的基本用法
1. 直接引用的对话/原文
2. 需着重论述或强调的内容
3. 特殊含义成分(别称/简称/反语)

### 单引号的使用场景
- **只在双引号内嵌套**时使用(外双内单)
- **不用于独立对话**(独立对话用双引号)

### 其他标点注意
- 省略号用 `……`(两个三连点),不用 `...` 或 `…`
- 破折号用 `——`(两个连字符)
- 逗号/句号/问号/感叹号用全角 `，。！？`
- 并列引号之间**不用顿号**(“日”“月”构成“明”字)

### 检测(每章定稿前)
```python
# 双引号左=右? 单引号左=右?
# ASCII " ' 残留?
# 双引号内嵌双引号?(嵌套错误)
# 独立对话误用单引号?
```

### 与 normalize_punct.py 的关系
- 脚本把 `「」→“”`、ASCII `"`→`“”`(成对)
- **但不处理**:嵌套规范(外双内单)、方向错误、独立对话误用单引号
- **脚本不能自动修正嵌套,需人工/LLM 核对**
