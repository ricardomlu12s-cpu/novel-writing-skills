# 中文叙事 AI 味特征清单(7 类)

基于 humanizer-guide 方法论 + humanise-text-skill 词表思路,针对中文小说创作。

## 模式 1:AI 高频词(直接替换)
| 词/短语 | 问题 | 改法 |
|---|---|---|
| 不禁 | 剥夺角色主动性 | 写角色的行动 |
| 仿佛/宛如/宛若 | 过度比喻,每段一次即多 | 用具体感知替代 |
| 映入眼帘 | 陈词滥调的视觉过渡 | 直接写看到了什么 |
| 心中暗道/暗自思忖 | 内心独白套话 | 删或改行动 |
| 沉声道/淡淡地说/缓缓说道 | 对话标签膨胀 | 统一"说"或删标签 |
| 脸色一变/身形一顿 | 反应套话 | 写具体生理反应 |
| 嘴角微扬/勾起一抹弧度 | 微笑套话(AI特征极强) | "他笑了"或删 |
| 不由自主/情不自禁 | 主体性剥夺 | 改角色主动行动 |
| 只见/此时此刻 | 场景过渡套话 | 直接切换 |
| 目光如炬/目光深邃 | 眼睛描写套话 | 写眼睛看向哪、做了什么 |

## 模式 2:弱化副词泛滥
微微/淡淡/缓缓/轻轻/悄然/默默/隐隐 —— 动词被削去力度。
- ~~他微微点了点头~~ → 他点了点头
- ~~她轻轻叹了口气~~ → 她叹气

## 模式 3:意义膨胀
- ~~这次会面意义深远~~ → 从那以后,他改变了用兵的方式
- ~~可谓是天下第一~~ → 删"可谓",直接陈述
- ~~此举前所未有~~ → 删,写具体发生了什么

## 模式 4:通用结论套话
- ~~展望未来,他充满希望~~ → 他把那封信折好,放进了锁匣。还有一件事没做完。

## 模式 5:论文式段落结构
- ~~不难看出,他已下定决心。接下来,他走向了马厩……~~ → 他走向了马厩,没有回头。

## 模式 6:正式语体入侵小说正文
公文/学术/新闻腔混进叙事(此外/然而/因此/综上所述),拉回口语/叙事语体。

## 模式 7:排比三连过多
- ~~他展现出了勇气、智慧和决断力~~ → 他很果断
- ~~这场战斗充满了激烈、残酷和牺牲~~ → 这场战斗死了很多人

## 有灵魂的写作 vs 干净但无灵魂
避免 AI 模式但仍无聊 = 写作失败。好的写作特征:
- **具体细节**替代抽象概括
- **行动驱动**替代状态描述
- **声音独特**——有个人印记
- **意外与摩擦**——怀疑/犹豫/杂乱,不完全"顺畅"

## 使用
- 检测:跑 `scripts/detect_aislop.py <文件>`(确定性,免费)。
- 改写:两遍式(先清 7 类,再 AI 自审),逐段用上表改法。
- 防误伤:与 learn-style 风格指纹配合,刻意风格(该作者特色)不算 AI 味。
