# 仿生创意引擎(Creative Brain)

**解决什么**: 拆书/学风格让 AI 输出更"像"目标,但也更**套路化**——AI 天然选"最可能的下一句"(收敛),而创意需要"跳出轨道"(发散)。本引擎用三个脑机制,把"发散"做成可执行的步骤。

## 三个脑机制 ↔ 三个脚本

| 脑机制 | 解决 | 脚本 |
|---|---|---|
| **海马体·主动遗忘** | 记细节→拖累联想 + token 膨胀 | `skeleton_forget.py` |
| **默认模式网络·远距联想** | 剧情被猜到、没新意 | `cross_domain.py` |
| **动力系统·势能守恒** | 情节平、无推进动力 | `potential_check.py` |

---

## 机制一: 骨架遗忘(Skeleton Forgetting)

**人脑原理**: 海马体记"骨架"(发生了什么事),不记"细节"(原话/具体用词)。细节靠当下重建。AI 相反——它把细节全记着,既烧 token,又让"相似场景"总往旧答案靠。

**对应动作**: 把已写章节/拆过的书,提炼成**去细节骨架**,只留"结构 + 因果"。

```
原文细节: 孤儿发现自己是救世主,被带到魔法学校,打败了宿敌
骨架提炼: 身份错位 → 责任觉醒 → 对抗既得权力 → 自我和解
```

**关键**: 骨架去掉"孤儿/救世主/魔法学校"这些**具体**,只留"身份错位/责任觉醒"这些**结构**。具体可以跨域替换,结构才能跨域重组。

```bash
python3 ~/.claude/skills/ideate/scripts/skeleton_forget.py <项目目录|章节文件> --out 骨架库
# 或对全局资产库的拆书产物做骨架化
python3 ~/.claude/skills/ideate/scripts/skeleton_forget.py --asset <作品名>
```

产出: 骨架库 `~/.omc/assets/plot/skeletons/`(即资产库 plot 库的骨架层)。

## 机制二: 跨域联想(Cross-Domain Recombination)

**人脑原理**: 默认模式网络(DMN)在"走神"时把**相距遥远的神经元群**随机连接,产生"灵光一现"。创意 = 远距联想,不是邻近联想。

**对应动作**: 把"骨架" × "无关领域的概念" 嫁接,产出全新情节候选。

```
骨架: 责任觉醒
× 领域概念(随机取): 债务继承 / 宇宙热寂 / 菌群共生 / 象棋残局
= 新情节候选:
  - "责任觉醒 × 债务继承" → 主角继承的不是财产而是上一代的"债"(某同人项目已验证这个方向)
  - "责任觉醒 × 菌群共生" → 主角的力量来自与体内共生体的谈判,而非继承
```

**概念库从哪来**(三层,从零依赖到高成本):
1. **内置概念库**(零依赖): 脚本内置 ~20 领域 × 每领域 3-5 个核心概念(见 references/concept-bank.md)。
2. **从资产库提取**(零依赖): 从已拆书/已写世界观里抽概念词,做**图结构随机游走**(NetworkX,纯本地)跳到"远邻概念"。
3. **向量检索**(可选,有 embedding 成本): 把当前情节向量化,找"语义相似但领域不同"的概念。用户本地有模型/API 时启用,见 references/vector-upgrade.md。

```bash
# 基础版(零依赖): 骨架 × 内置概念库随机嫁接
python3 ~/.claude/skills/ideate/scripts/cross_domain.py --skeleton "责任觉醒" --n 5

# 图联想版(需 NetworkX,纯本地): 从资产库概念图随机游走取远邻
python3 ~/.claude/skills/ideate/scripts/cross_domain.py --skeleton "责任觉醒" --graph --n 5
```

**防乱编**: 嫁接产出是**候选**,不是定稿。每个候选过 `plan-plot` 的常识矩阵 + 读者共鸣 + 世界框架守恒三问,不合理的丢弃。

## 机制三: 势能引擎(Potential Energy)

**人脑原理**: 动机系统靠"欲望-满足"的**势能差**驱动行为。欲望越强、障碍越高、蓄势越足,释放越有力量。情节平淡 = 势能差不够。

**对应动作**: 每个情节段检查四拍是否齐、势能差够不够:

```
欲望(角色想要什么) → 障碍(什么挡住) → 蓄势(张力积累) → 释放(爆发/反转)
势能差 = 欲望强度 × 障碍高度 × 蓄势时长
```

```bash
python3 ~/.claude/skills/ideate/scripts/potential_check.py <章节文件>
# 检查: 有欲望吗?有障碍吗?蓄势够吗?释放到位吗?势能差够吗?
```

- **势能差不够** → 情节平、读者"没感觉"。脚本标出缺哪一拍。
- 与 plan-plot 的"高潮调度/情绪曲线"联动: 情绪曲线是"结果",势能四拍是"原因"。

## 使用流程(卡创意时)

1. **骨架化**: 把当前卡住的剧情/已写章节提炼骨架。
2. **跨域嫁接**: 骨架 × 无关概念 → 5 个新情节候选。
3. **过筛**: 候选过常识矩阵 + 世界守恒 + 读者共鸣,留 1-2 个。
4. **势能检查**: 对选中候选跑 potential_check,补足欲望/障碍/蓄势/释放。
5. **喂给 write-chapter**: 把选中的新情节写进大纲,继续写。

## 防套路铁律(本引擎与 plan-plot 的分工)

- plan-plot 的"反套路库"是**规避式**(知道什么老套,避开)。
- ideate 是**生成式**(主动造新情节)。
- 两者配合: 先用 ideate 造新方向,再用 plan-plot 反套路库扫掉"看似新、其实是变相老套路"的候选。

## 更高级形式(升级路径,当前用 skill 足够)

- **向量检索联想**(embedding): 概念库变大后,图随机游走质量下降,换向量检索找"语义远邻"。见 references/vector-upgrade.md。
- **MCP server**: 当需要**跨会话持久概念图**、或联想要访问外部知识源时,把 concept-bank/图检索做成 MCP 工具,让 Claude 直接调用。当前阶段文件+脚本够用,先不引入进程常驻。

## 喂给谁 / handoff
- **reuse-assets**: 骨架产出进 plot 库;概念从 deconstruction/technique 库提取。
- **plan-plot**: 候选过常识/反套路/世界守恒。
- **write-chapter**: 选中的新情节写进大纲续写。
- **evolve-style**: "跨域联想成功次数"进能力画像(手法增广)。
