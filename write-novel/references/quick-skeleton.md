# 开书骨架批量写入(Quick Skeleton)

**借鉴 Open Write**:开书时一次完整写入建整套项目骨架,少权限打断、提速。只建设定(骨架),不碰正文(正文仍走质量门)。

## 骨架清单(一次写入建全套)
```
<项目目录>/
├── ACTIVE                      # 激活标记(磁盘为准,记忆为辅)
├── platform-config.md          # 平台参数(起点/番茄)
├── world.md                    # 世界观(规则/势力/地理)
├── characters/                 # 角色卡(四维/战力/声线/独特内核)
│   ├── 001-主角.md
│   └── ...
├── foreshadowing.jsonl         # 伏笔注册表
├── relationships.jsonl         # 关系网
├── timeline.md                 # 时间线
├── canon-ledger/               # 正典账本(facts/promises/rules)
├── genre-knowledge.md          # 题材知识库
├── power-system.md             # 战力系统
└── panel/                      # (渲染后)创作面板
```

## 内容模板(各文件)

### world.md
```markdown
# 世界观
## 世界规则(L1 公理)
1. <硬规则,永不漂移>
## 势力
- <势力名>: <定位>
## 地理
- <地点>: <特点>
## 历史
- <关键事件>
```

### 角色卡(主角模板)
```markdown
# 角色: <名>
## 基础
- 身份/年龄/外貌/性格
## 四维卡
- 显性目标/隐性需求/创伤心结/言语防线
## 独特内核
- 专属金手指形态/独特信念/专属怪癖/独特缺陷
## 战力
- 等级/战力值/成长曲线
## 声线
- 口头禅/句式/词汇域/回避
```

### foreshadowing.jsonl / relationships.jsonl / timeline.md
- 空骨架(可追加的结构),先建文件再登记。

## 批量写入方式(Open Write 思路)
- **一次完整写入**:每个文件用一次写入(Write)建好,而非零碎 Read-Edit。
- **一次性授权**:开书时用户授权"建设定骨架",全程少权限打断。
- **骨架≠正文**:骨架是设定(批量建安全),正文仍逐章过质量门(不可批量)。

## 检查清单(开书批量建)
- [ ] 骨架文件齐全?(world/角色卡/账本/配置)
- [ ] 平台参数注入了吗?(起点/番茄)
- [ ] 题材知识库加载了吗?(genre-knowledge)
- [ ] 团队查新/结构查新过了吗?(novel-team-composition/structure-cliche)
- [ ] 激活标记写了吗?(ACTIVE 磁盘为准)

## 与 Open Write 的边界
- **学**:批量完整写入(少打断/快开书)。
- **不学**:批量写正文(正文必须过质量门,物理隔离)。
