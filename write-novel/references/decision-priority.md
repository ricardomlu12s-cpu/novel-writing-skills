# 创作裁决优先级(Decision Priority)

**问题**:创作链的约束散落在多个文件(方向基准/雷区/命运改写负责制/杀伐守卫/血统代价/反套路黑名单/世界框架守恒…)。写到关键场景时,多个约束可能互相打架,缺一组**显式的"冲突时谁优先"**铁律。借鉴《龙族人生模拟器》的规则优先级(P0-P10),落到纯创作语境。

> **用途**:只在约束冲突时裁决。平时各约束并行不悖,不冲突就不需要调优先级。

## 优先级(高 → 低)

| 级 | 约束 | 来源文件 | 含义 |
|---|---|---|---|
| **P0 作者元指令** | 用户当前明确指示 | 会话上下文 | 用户刚说的"这次要 X",凌驾一切(但只在本次/本场景生效) |
| **P1 创作宪法** | 不能烂尾/主线不能草/不为多写而多写 | 方向基准 / chapter-map 尾部 | 最高铁律,不可被单章技巧突破 |
| **P2 世界框架守恒** | S级绝对公理不可穿透 | source-canon/canon.md 守恒层级 | 蝴蝶效应再大,世界背景框架必须守恒 |
| **P3 已锁定事实** | 已写定稿的正文/正典账本 facts | canon-ledger/facts.jsonl | 已发生的事实不可推翻(死人不能无解释复活) |
| **P4 命运改写负责制** | 改写命运=承担余生 | fate-responsibility.jsonl | 被救/被改写角色要有持续有分量的戏份 |
| **P5 角色内核不 OOC** | 固定角色硬红线/人格锁 | source-canon 角色卡 + supporting-cast | 配角/反派不因剧情需要而降智/洗白/性格突变 |
| **P6 世界底层规则** | 战力/血统/言灵/地理/时代 | power-system.md + world.md | 体系内原创,不过守恒三问不炫设 |
| **P7 因果关系** | 改锚点必须重排下游 | butterfly-ledger.jsonl | 蝴蝶效应沿因果链推演,不跳因果 |
| **P8 风格一致性** | 目标指纹 vs 实际指纹 | learn-style + evolve-style | 不脱风格,但个人化偏差可升级(不锁死) |
| **P9 读者共鸣/软质量** | 节奏/共鸣/文学功底 | plan-plot + apply-feedback | 不量化的软质量,读者反馈是最终检验 |
| **P10 戏剧效果/爽点** | 高潮/打脸/反转 | plan-plot | **最低优先级,永远不牺牲 P1-P8** |

## 铁律(三条)

1. **不为了 P10(爽点)牺牲 P1-P8**。这是最常犯的:为了一个爽点,让角色降智/让因果断裂/让战力崩坏/让世界观矛盾。→ 爽点必须长在人物逻辑 + 世界规则之上。
2. **P3(已锁定事实) > P7(因果推演)**。已经写进定稿的事实是"过去",比"未来该怎么推演"更硬——推演错了可以改方向,写定的事实不能悄悄推翻。
3. **P5(角色内核)不因 P10 妥协,但可因 P4(命运改写)松动**。角色可以被蝴蝶效应改变,但改变必须有因果动机 + 记录在角色双轨,不能"为了剧情强行改人设"。

## 冲突裁决示例

| 冲突 | 裁决 |
|---|---|
| "这里打脸很爽,但会暴露主角能力让暴露度跳级" | P3/P5 > P10 → 不为了爽点让世界不查主角 |
| "让这个反派洗白,剧情更有反转感" | P5 > P10 → 洗白须 ≥3 铺垫(杀伐守卫),否则不洗 |
| "这里让路明非直接开挂秒杀,读者爽" | P4(心智成长同步) > P10 → 空有力量心智仍衰仔 = 雷区,不写 |
| "改这个源作事件,主线会更精彩" | P2/P7 > P10 → 先过守恒三问 + 登记蝴蝶效应再改 |

## 接入方式

- write-chapter 质量门:当两个约束打架时,调本表裁决,而非"凭感觉取舍"。
- 写完后复盘(evolve-style L2/L3):检查本章是否为了爽点牺牲了 P1-P8。
