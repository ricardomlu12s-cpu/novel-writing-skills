# 注入策略(Injection Policy)

**"无意识的严格自动化"的落地。** 采集/检测/轻量注入全自动,重量注入分级 + 作者裁决位。定义什么自动、什么要问,防止"自动化但没有灵魂的进步"。

## 分级注入矩阵

| 注入类别 | 内容 | 自动化 | 作者裁决 |
|---|---|---|---|
| **轻量注入** | 手法提醒(白金已掌握/待练)、薄弱维度 lessons、Stop/Avoid 避坑、下一情节节奏建议、**防固化变化注入**(新手法推荐/陌生化练习/限用令) | **全自动,持续** | 无 |
| **中等注入** | L3 弧段 Adopt/Avoid 调整、下弧手法重定向 | 自动生成决策,确认后生效 | **有** |
| **重量注入** | 指纹升级(个人化→作者指纹库)、风格重定向、能力画像定稿、L4 卷级参数 | 自动生成决策,展示证据,确认后生效 | **有(强制)** |
| **终结注入** | L5 全书风格史 + 作者指纹库定稿 + 反哺 style-library | 完结时一次,确认 | 有 |

## 作者裁决位的操作方式

- 触发时展示:**偏差证据(跨章统计/读者反馈/质量门)+ 拟处置 + 备选**。
- 作者三选:**采纳 / 否决(降为漂移拉回)/ 暂缓(标记待观察)**。
- 不裁决 → 默认暂缓(不自动生效),不会"未经确认升级风格"。

## 为什么必须有裁决位(创作规律)

- 人类作者的"主动反思"才有效——作者点头的进化才是真进化。
- 全自动升级风格的风险:系统把某些偏差误升为"个人风格",把作者拉得太远(失去模仿基准),或把 AI 味误当个人化。
- 自动采集 + 手动拍板 = **既有机制的速度,又有人类作者的方向感**。

## 采集与检测(全自动,无感)

| 数据源 | 自动化点 |
|---|---|
| 每章质量门结果 | 自动追加 lessons |
| 检测脚本信号(remove-ai-tone / plan-plot) | 自动登记 cadence |
| 读者反馈分级 | 自动登记,堆积自动触发学习 |
| 指纹扫描 | 每章后自动更新 actual 指纹 |
| 能力画像 | 每卷自动生成初稿 |

## 注入时效(防上下文膨胀)

- **轻量注入**:每章装配时注入,恒定大小(薄弱维度 lessons 3-5 条)。
- **中等/重量注入**:只在结构节点注入,进大纲/装配,不进日常章。
- **旧 lessons**:归档(见 capability-model 降级归档),不占用上下文。

## 防注入失效

- lessons 连续 N 章重犯旧错 → 该条标记"降级/重写",深度复盘。
- 轻量注入 3 次无效 → 升中等注入,作者裁决。

## 边界

- 采集检测**永不跳过**(严格):触发即执行。
- 重量注入**永不自动生效**(严格):必须裁决。
- 这是"无意识"的准确定义:过程全自动,方向有人。
