# 五级分层学习(Learning Layers)

现有 lessons 只有一层、注入"最近3条"、不分级。本机制升级为五级,一级管一级,产出是**决策**不是纪要。

## 五级规格

| 层 | 时机 | 学什么 | 产出 | 注入方式 | 自动化 |
|---|---|---|---|---|---|
| **L1 章内即时** | 每章质量门后 | 本章手法得失(几行) | 追加 `lessons.md`(Keep/Stop/Improve/Avoid) | 下一章注入 | 全自动 |
| **L2 情节学** | 情节节点闭合 | 该情节节奏/共鸣/手法复盘 | L2 摘要进 lessons | 下一情节定向注入 | 全自动 |
| **L3 弧段学** | 弧闭合 | 弧级风格校准 + **指纹对比** | 指纹偏差报告 | 下弧 Adopt/Avoid 调整 | 采集自动,重定向裁决 |
| **L4 卷学** | 卷边界 | 全卷风格画像 + **能力画像** | 卷画像 + 能力曲线 | 下卷参数 + 待练手法 | 画像自动,裁决 |
| **L5 全书学** | 完结 | 风格史 + 能力成长曲线 | 作者指纹库定稿 | 反哺 style-library | 完结时一次 |

## 每级产出格式(决策,非纪要)

### L1(章内,追加 lessons.md)
```markdown
## 第12章 沉淀
### 有效的(Keep)[证据:质量门通过+情绪曲线达标]
- 打脸用"延迟反噬",读者反应好 → 可复用
### 失效的(Stop)[证据:读者差评]
- 反派降智被吐槽 → 下章恢复智商在线
### 待改进(Improve)[证据:张力值未达标]
- 高潮张力只到6 → 下章目标8
### 避坑(Avoid)[证据:检测命中]
- 别用"嘴角微扬"(AI味) → 已入禁用词
```

### L2(情节学,进 lessons + cadence)
```markdown
## 情节节点【学院篇·入学考】闭合复盘
- 节奏:铺垫过长,爆点后置 → 下情节前移
- 共鸣:3E考试悬念 OK → 保持
- 手法:伏笔"衰小孩"回收成功 → 复用该回收节奏
```

### L3(弧段学,指纹对比)
```markdown
## 弧段【初入卡塞尔】指纹对比
- 目标指纹:短句留白(龙族) vs 实际:长句密度略高
- 偏差分类:漂移(拉回)/ 个人化(升级候选)/ 待改进
- 处置:中段长句是个人化候选,待作者确认
```

### L4(卷学,卷画像 + 能力画像)
```markdown
## 卷1 能力画像
- 手法掌握:留白✓ 双线✓ 打脸✓ / 待练:群像POV切换 ✗
- 薄弱维度:对话密度
- 指纹变迁:句长 15.2 → 16.8(个人化候选)
- 下卷定向练:群像POV + 对话密度
```

### L5(全书学,风格史 + 作者指纹库定稿)
```markdown
## 全书风格史
- 指纹轨迹:模仿(卷1)→ 分化(卷2)→ 成型(卷3)
- 作者指纹库定稿:短句密度 + 冷笔触 + 群像意识流
- 反哺 style-library:沉淀为个人风格库
```

## 注入策略(替代"最近3条")

- **默认**:按当前章节的**薄弱维度**定向注入(能力画像里标弱的),而非固定取最近3条。
- **L1 保留最近3条**:紧急/章节级教训就近注入。
- **结构节点**:L3/L4 学习产出直接注入下一弧/卷的参数。

## 与既有机制衔接

- **lessons 飞轮**(write-chapter):L1 保留在飞轮,防污染铁律(证据门槛/分层可信度/错误样本隔离)对 L2–L5 同样适用。
- **cadence 引擎**:每级的触发时机由 cadence.jsonl 判定(结构锚点/信号/间隔)。
- **evolve-style 脚本**:L3/L4 指纹对比、能力画像由脚本产出初稿,LLM 出决策。
