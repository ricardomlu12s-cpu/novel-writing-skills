# 风格指纹双轨进化(Dual-Track Fingerprint)

**自主风格形成的核心机制。** 把 learn-style 的静态指纹改成双轨,让"模仿 → 自主"从人治变机制自动识别 + 作者最后拍板。

## 核心转变

**旧(静态)**:风格指纹一旦注入,永不修正。每章"风格校准"把作者拉回模仿对象——**个人化偏差被当成漂移消灭**。

**新(双轨)**:持续记录"实际写出的风格 vs 目标基准"的偏差。偏差稳定 + 作者确认 = 沉淀为个人指纹。**偏差是自主风格的种子,不是错误。**

## 双轨定义

```
目标指纹  (来自模仿对象,learn-style 提取)   ── 静态基准,写入 style-library/<风格名>/fingerprint.md
实际指纹  (来自已写定稿,检测脚本统计)      ── 动态,随每章更新,存 evolution/fingerprint-actual.md
```

## 实际指纹统计维度(与目标指纹同构,才能对比)

| 维度 | 统计方式(脚本) |
|---|---|
| 句长均值/方差 | 分句计数 |
| 段长分布 | 段落长度分桶 |
| 标点密度 | 省略号/破折号/逗号 频率 |
| 对白密度 | 引号句占比 |
| 情感浓度 | 情绪词频 |
| 留白度 | 短段落占比 |

## 偏差三分类处置

| 偏差类型 | 判据 | 处置 |
|---|---|---|
| **漂移**(拉回) | 无意识的滑回习惯/AI 腔(如突然开始堆排比) | 校准 + 记 lessons(Avoid) |
| **个人化**(升级) | **稳定的、跨多章重复的、作者确认认可的差异** | 升级进 `fingerprint-author.md` → 这就是自主风格 |
| **待改进**(标记) | 读者反馈否定的稳定差异 | 标记弱项 → 进能力画像(capability.md) |

## 三区模型(防固化,升级版)

偏差分类升级为**三区**,新增「锁死区」——**偏差≈0 不是模仿成功,是表达固化**:

| 区 | 偏差水平 | 含义 | 处置 |
|---|---|---|---|
| **锁死区** | 偏差 ≈ 0 | 表达固化,不是模仿成功 | **主动去中心化**:注入变化、刻意练习、风格重定向 |
| **健康区** | 中等偏差 | 个人化正在形成 | 正常进化,个人化候选升级 |
| **失控区** | 偏差过大 | 脱离基准/丢失模仿价值 | 拉回(原"漂移") |

**核心转变**:原方案把"偏差小"当好事,现在偏差≈0 反而告警。完整防固化机制见 `references/anti-rigidity.md`。

## 判定流程

```
L3/L4 学习时:
  1. 脚本对比 实际 vs 目标 → 列出偏差 + 偏差水平(自动)
  2. 偏差≈0 → 锁死区 → 主动去中心化(注入变化/新手法)
     中等偏差 → 健康区 → 个人化候选升级流程
     偏差过大 → 失控区 → 拉回
  3. 分类:漂移 / 个人化候选 / 待改进(LLM 初判)
  4. 作者确认:个人化候选 → 确认"这是我想要的风格?"(裁决位)
  5. 确认 → 升级进作者指纹库;否 → 降为漂移拉回
```

## 关键判据(个人化 vs 漂移,防误升级)

**升级为个人风格,必须同时满足**:
1. **跨多章重复**(≥3 章稳定出现,非偶发)。
2. **有创作意图**(该差异是作者主动表达,非无意识习惯)。
3. **读者不反对**(无稳定差评指向该差异)。
4. **作者确认**(最终裁决位)。

## 作者指纹库(fingerprint-author.md)

```markdown
# 作者指纹库
## 已沉淀的个人风格
- 短句 + 冷笔触收尾(自卷2稳定出现,读者正向)
- 群像意识流 POV 切换(自卷3)
## 漂移记录(拉回)
- 排比三连(卷1泛滥 → 已拉回,入 Avoid)
## 待练手法(能力画像)
- 群像POV / 对话密度
```

## 回流

- 个人化升级 → 回流 style-library(可选,标注"作者原创成分",与模仿对象区分)。
- 这保证:模仿对象的指纹是**参考**,作者自己的指纹是**资产**,两者不混。

## 与 remove-ai-tone 的配合

- remove-ai-tone 判定"AI 味"用的是**通用 AI 指纹**;本引擎判定"个人化"用的是**作者自己的稳定偏差**。两者不同:AI 味要清,个人化要留。
- 若某差异同时被 remove-ai-tone 标 AI 味 + 被本引擎标个人化 → **优先查是否真 AI 味**,别把 AI 味误当个人风格。
