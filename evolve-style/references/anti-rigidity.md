# 防固化(Anti-Rigidity)

**模仿文风 ≠ 固化。** 本机制防的是六大表层维度(句式/用语/修辞/词汇/表达/写作手法)在模仿中被锁死,进而反噬为"思想固化"。文学史上风格固化 = 创作生命终结(晚年重复自己)。

## 核心原则

> **风格生命力 = 稳定的个人内核 + 流动的表达表层。**

- **内核(作者指纹库)**:少而精,可演进(经作者裁决才变)。
- **表层(表达六维)**:必须流动——**偏差为零和偏差过大都是病**,健康区间才算成长。

## 表层六大维度

| 维度 | 内容 | 固化表现 |
|---|---|---|
| 句式 | 句子长短、节奏、结构模式 | 全篇同一句式节奏 |
| 用语 | 常用词、连接词、语气词 | 高频词反复 |
| 修辞 | 比喻/排比/设问/用典 的取用方式 | 同一修辞套路 |
| 词汇 | 词域、词频、造词习惯 | 词汇库锁死 |
| 表达 | 叙述视角、留白密度、情绪呈现 | 同一表达范式 |
| 写作手法 | 结构/伏笔/高潮/刻画 的技术套路 | 手法万年不变 |

## 三区模型(替代"偏差=漂移=错")

每次 L3/L4 双轨对比,偏差分**三区**,处置不同:

| 区 | 偏差水平 | 含义 | 处置 |
|---|---|---|---|
| **锁死区** | 偏差 ≈ 0 | 表达固化,不是模仿成功 | **主动去中心化**:注入变化、刻意练习(见下) |
| **健康区** | 中等偏差 | 个人化正在形成 | 正常进化,个人化候选升级 |
| **失控区** | 偏差过大 | 脱离基准/丢失模仿价值 | 拉回,防漂移 |

**核心转变**:原方案把"偏差小"当好事,现在**偏差≈0 反而告警**。

## 主动去中心化(锁死区处置)

**采集上**:
- 偏差≈0 → 告警(rigidity_scan.py 自动)。

**轻量注入(全自动)**:
- **新手法推荐**:从待练手法池(能力画像)定向注入一个"本轮尝试的新手法",写进下一弧装配。
- **陌生化练习**:目标指纹里**不常用**的句式/修辞,本轮定向练(打破舒适区)。
- **限用令**:对高频词/高频句式,限用(如"本轮少用'不禁'")。

**重量注入(作者裁决)**:
- **风格重定向**:当前模仿对象已吸收透 → 换一个新模仿对象(或加新源),注入新手法。

**手法轮换**(能力画像):
- 已掌握手法不再高频使用(避免熟练即固化),**轮换不同手法**保持新鲜。
- 待练手法定向练 → 练熟后进入轮换池 → 定期轮换。

## 与双轨指纹的关系

双轨模型升级为**三区模型**:
- `dual-track-fingerprint.md` 的"漂移(拉回)"保留(对应失控区)。
- 新增"锁死区"防固化。
- **判定防误伤**:某差异同时被标 AI 味 + 个人化 → 先查真 AI 味;锁死区告警 vs 个人化候选 → **优先查锁死**(防把固化当个人风格)。

## 检测脚本

```bash
python3 ~/.claude/skills/evolve-style/scripts/rigidity_scan.py <项目目录>
```

- 六大维度偏差扫描,偏差≈0 → 锁死区告警(自动)。
- 高频词/高频句式/复用修辞 → 列出(供限用令)。

## 与 remove-ai-tone 的配合

- remove-ai-tone 清"AI 味"(通用 AI 腔);本机制防"模仿固化"(锁死目标指纹)。
- **两者的重合区**:固定套路(排比三连)——AI 味要清,模仿固化也要防,同一套限用令工具可复用。

## 与 evolve-style 主线的关系

- 防固化是双轨指纹的**第三态**(锁死区),不是独立机制。
- 触发、注入、裁决走同一套 cadence + injection-policy。
- 作者裁决位:**风格重定向 / 新模仿对象 / 限用令**,必须有作者确认。
