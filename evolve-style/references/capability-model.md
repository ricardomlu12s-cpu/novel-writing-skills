# 能力画像(Capability Model)

写作能力的**可测量进步模型**。四通道:错误修复 / 手法增广 / 知识积累 / 能力曲线。能力画像每卷更新,跨卷对比看"是否真的在进步"。

## 四通道

| 通道 | 机制 | 自动化点 |
|---|---|---|
| **错误修复** | lessons 的 Stop/Avoid 区按证据强度注入;连续多章不再犯 → 降级归档 | 注入改**定向**:读能力画像薄弱维度 → 取该维度 lessons → 注入,替代"最近3条" |
| **手法增广** | 对照白金手法清单,识别"已掌握/待练",下卷定向练 | 每卷学自动生成"待练手法"注入大纲 |
| **知识积累** | 写过的世界规则/史料/技法沉淀进 genre-knowledge | 每章定稿自动追加 |
| **能力曲线** | 每卷画像跨卷对比 | 进面板可视化 |

## 手法轮换(防熟练即固化)

- 已掌握手法**不再高频使用**(熟练即固化)——轮换不同手法保持新鲜。
- 待练手法定向练 → 练熟后进轮换池 → 定期轮换。
- 与 anti-rigidity 的"主动去中心化"联动:限用令 + 新手法推荐都走本池。

## capability.md 结构

```markdown
# 能力画像
## 手法掌握度(对照白金手法清单)
- 已掌握:留白✓ 双线✓ 打脸✓ 冷笔触✓
- 待练:群像POV ✗ 意识流心理 ✗ 节奏缓冲 ✗
## 薄弱维度(读者反馈 + 质量门证据)
- 对话密度(卷1连续3章C级反馈)
- 高潮张力值(均6.2,目标8)
## 错误修复记录
- 排比三连:卷1泛滥 → 卷2无复发(Avoid 生效,归档)
- 反派降智:卷1被吐槽 → 卷2恢复(Stop 生效)
## 知识积累
- 卡塞尔学院设定 / 言灵体系 / 江南技法
## 能力曲线(跨卷)
- 卷1:句长15.2 对白比32% 张力6.2
- 卷2:句长16.8 对白比38% 张力7.1
- 趋势:对白密度↑ 张力↑ → 定向练习生效
```

## 手法掌握度判定(手法增广)

- 来源:plan-plot `platinum-craft.md` 白金手法清单(10类)。
- 判定:某手法在最近 2-3 章**被质量门确认为"用得好"** → 记为已掌握。
- 未出现 / 用了但被读者否定 → 待练。
- **下卷注入**:待练手法写进大纲/装配,定向练。

## 错误修复的"降级归档"

- Stop/Avoid 条目连续 3+ 章不再触发 → 从注入区降级为"归档"(不再占用上下文)。
- 归档记录保留证据(防复犯时能查回)。

## 能力曲线数据源

- 每卷能力画像(evolution/capability.md)跨卷追加。
- 进创作数据面板可视化(plan-plot 情绪曲线 + 本引擎能力曲线同区)。

## 防幻觉(证据门槛)

- 能力画像只记**有证据的**:质量门结果 / 读者反馈 / 检测脚本 / 跨章统计。
- "我感觉自己进步了"不写入;曲线必须由数据支撑。

## 与既有机制衔接

- **plan-plot**:白金手法清单 ↔ 能力画像双向。
- **build-world 面板**:能力曲线进面板。
- **apply-feedback**:薄弱维度由读者反馈 C 级堆积触发。
- **evolve-style 脚本**:evolution_report.py 读 evolution/ + lessons 生成画像初稿。
