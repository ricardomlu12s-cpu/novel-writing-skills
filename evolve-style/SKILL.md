# Creative Evolution — 创作进化引擎

横切机制。**风格模仿 → 自主风格 → 能力进化**的三层演进。定位同 token-ops:不是链上某环,而是整条链的进化层——**越写越好靠机制,不靠"我尽量记住"**。

## 核心理念(四句话)

1. **偏差 ≠ 错误**。你实际写出的风格和目标基准的稳定偏差,是自主风格的种子。现有系统的最大误区是**每章风格校准把作者拉回模仿对象,把个人化当成漂移消灭**。本引擎把这个逻辑倒过来:漂移该拉回,个人化该升级。
2. **学习的节拍是"结构",不是"章节数"**。人类作者不是在第 10 章反思,是在**卷闭合、弧闭合、情节走完、写崩了**时反思。固定"每 N 章"总结违背创作规律——机制必须以结构为节拍器,以信号为触发器,篇幅只管定粒度。
3. **采集由写章流程自动触发 + 轻量注入全自动,重大节点作者裁决**。采集、检测、日常手法注入随写第X章自动发生(无需作者额外提醒);指纹升级、风格重定向、能力画像这些"改变方向"的决策,保留作者确认位。
4. **模仿文风 ≠ 固化**。六大表层维度(句式/用语/修辞/词汇/表达/写作手法)在模仿中被锁死,会反噬为**思想固化**。风格生命力 = **稳定的个人内核 + 流动的表达表层**——偏差为零和偏差过大都是病,健康区间才算成长。

## 防固化(抗思想固化)

**模仿文风 ≠ 固化**。防六大表层维度被模仿锁死,进而反噬为思想固化。核心是**三区模型**:

| 区 | 偏差水平 | 含义 | 处置 |
|---|---|---|---|
| **锁死区** | 偏差 ≈ 0 | 表达固化(不是模仿成功) | **主动去中心化**:注入变化、刻意练习、风格重定向 |
| **健康区** | 中等偏差 | 个人化正在形成 | 正常进化 |
| **失控区** | 偏差过大 | 脱离基准 | 拉回 |

**主动去中心化**(锁死区):新手法推荐 + 陌生化练习(练目标指纹里不常用的表达)+ 限用令(限高频词/句式)+ 风格重定向(换模仿对象,作者裁决)。**手法轮换**:已掌握手法不高频使用,避免熟练即固化。

完整机制见 `references/anti-rigidity.md`。

## 三大自适应维度(节律引擎)

**触发优先级:结构锚点 > 信号阈值 > 间隔兜底。三者取最早。**

### 维度一:篇幅尺度(定粒度,随作品实际长度动态重算)

| 档位 | 预计总章数 N | 小学习间隔 | 中学习间隔 | 大学习 |
|---|---|---|---|---|
| 短篇 | ≤40 | max(3, N/12) | max(10, N/4) | 全书 1 次 |
| 中篇 | 41–100 | max(4, N/12) | max(12, N/5) | 每卷 + 全书 |
| 长篇 | 101–300 | max(6, N/12) | max(20, N/6) | 每卷 + 全书 |
| 超长篇 | 301+ | max(8, N/12) | max(30, N/7) | 每卷 + 全书 |

- **间隔是初值,不是铁律**。每次学习后按作品**实际长度**重算(已写章数 ÷ 细纲覆盖率 外推总长;或 卷弧数 × 每弧预计章数 上推)。写到一半发现实际更慢,N 变大间隔变宽,反之收窄。**数字跟着作品长,不跟日历。**
- 完整公式与示例见 `references/cadence-engine.md`。

### 维度二:结构尺度(定锚点,优先于一切)

总纲细纲在,就不用猜间隔——结构节点就是硬锚点:

| 结构锚点 | 触发层级 | 依据 |
|---|---|---|
| 卷边界 | 大学习(L4) | 总纲 `plan.md` |
| 剧情弧闭合 | 中学习(L3) | 细纲弧边界 |
| 情节节点闭合(因果链走完) | 小学习(L2) | 细纲 `chapter-outlines/` 情节单元 |
| 地图/题材/时间跳跃 | 强制风格校准 | 最易漂移点 |
| 新角色批量登场(≥3) | 声线/对话密度校准 | 角色卡 |
| 状态机联动缺失告警 | 中学习(L3) | plan-plot |

> 就算没到间隔,弧一闭合就学——文学上"一个因果链走完"才是自然反思点,人类作者也是在那停笔的。

### 维度三:信号尺度(定触发,非计划内)

| 信号 | 阈值 | 触发 |
|---|---|---|
| 风格漂移 | 检测超阈值 | 立即小学习 + 指纹核对 |
| AI 味命中率 | 连续 2 章高 | 小学习 + remove-ai-tone 加强 |
| 质量门同类问题 | 连续 3 章同一类 | 中学习(查系统问题) |
| 读者反馈 C 级 | ≥3 条指向同一维度 | 中学习 |
| lessons 注入失效 | 连续 N 章重犯旧错 | 深度复盘,标记该条降级/重写 |

## 五级分层学习(L1–L5)

现有 lessons 只有一层,学习不分级、注入"最近3条"。改为五级,一级管一级:

| 层 | 时机 | 学什么 | 产出 | 注入方式 |
|---|---|---|---|---|
| **L1 章内即时** | 每章质量门后 | 本章手法得失(几行) | 追加 `lessons.md` | 下一章注入 |
| **L2 情节学** | 情节节点闭合 | 该情节节奏/共鸣/手法复盘 | L2 摘要进 lessons | 下一情节定向注入 |
| **L3 弧段学** | 弧闭合 | 弧级风格校准 + **指纹对比** | 指纹偏差报告 | 下弧 Adopt/Avoid 调整 |
| **L4 卷学** | 卷边界 | 全卷风格画像 + **能力画像** | 卷画像 + 能力曲线 | 下卷参数 + 待练手法 |
| **L5 全书学** | 完结 | 风格史 + 能力成长曲线 | 作者指纹库定稿 | 反哺 style-library |

**每级产出是"决策",不是"总结纪要"**——纪要没人看,决策会注入。完整层级规格见 `references/learning-layers.md`。

## 风格指纹双轨进化(自主风格形成的核心)

把 learn-style 的静态指纹改成**双轨**:

```
目标指纹  (来自模仿对象,learn-style 提取)   ── 静态基准
实际指纹  (来自已写定稿,检测脚本统计)      ── 动态,随每章更新
```

每次 L3/L4 学习时对比双轨,算偏差,分三类处置:

| 偏差类型 | 判据 | 处置 |
|---|---|---|
| **漂移**(拉回) | 无意识的滑回习惯/AI 腔 | 校准 + 记 lessons |
| **个人化**(升级) | **稳定的、跨多章重复的、作者确认认可的差异** | **升级进作者指纹库 → 这就是自主风格** |
| **待改进**(标记) | 读者反馈否定的稳定差异 | 标记弱项 → 进能力画像 |

**自主风格不是"设定的",是"检测出来的"**:机制持续记录"实际写出的风格 vs 目标基准的偏差",偏差稳定 + 作者确认 = 沉淀为个人指纹。模仿→自主的转化从"人治"变"机制自动识别 + 作者最后拍板"。完整双轨机制见 `references/dual-track-fingerprint.md`。

## 能力进化(错误修复 / 手法增广 / 知识积累)

| 进化通道 | 机制 | 自动化点 |
|---|---|---|
| **错误修复** | lessons 的 Stop/Avoid 区按证据强度注入;连续多章不再犯 → 降级归档 | 注入改**定向**:读能力画像薄弱维度 → 取该维度 lessons → 注入,替代"最近3条" |
| **手法增广** | 对照白金手法清单,识别"已掌握/待练",下卷定向练 | 每卷学自动生成"待练手法"注入大纲 |
| **知识积累** | 写过的世界规则/史料/技法沉淀进 genre-knowledge | 每章定稿自动追加 |
| **能力曲线** | 每卷画像跨卷对比 | 进面板可视化,看自己是否真的在进步 |

完整能力模型见 `references/capability-model.md`。

## 节律账本 + 进化账本(两个新文件)

```
<项目目录>/
├── cadence.jsonl        # 节律账本:每次学习的 上次/下次/触发原因/间隔重算值
├── evolution/           # 进化履历
│   ├── fingerprint-actual.md  # 实际指纹(动态,脚本统计)
│   ├── fingerprint-author.md  # 作者指纹库(个人化升级沉淀)
│   ├── capability.md          # 能力画像(手法掌握/薄弱维度/待练)
│   └── evolution-report.md    # 进化学报告(小/中/大)
└── lessons.md           # 既有飞轮,升级为 L1-L5 五级
```

- **cadence.jsonl 与伏笔/承诺状态机同一套 append-only 逻辑**:只追加,不改历史。系统读它就知道"现在该不该学",不依赖模型自觉。
- 账本 schema 见 `references/cadence-engine.md`。

## 执行协议(自适应学习流水线)

```
【采集(每章,由 write-chapter 定稿后触发,非 hook 全自动)】
  质量门结果 → 检测脚本信号 → 读者反馈分级 → lessons 追加 → cadence 账本登记

【节律判定(每章后/结构节点后)】
  读 cadence.jsonl → 检查 结构锚点? 信号阈值? 间隔到期?
  → 未触发:登记"已检查",静默
  → 触发:跑对应层级学习

【层级学习(小/中/大)】
  L2/L3:跑 fingerprints / 能力画像 / 偏差分类 → 出决策 → 轻量注入
  L4:卷画像 + 能力曲线 + 待练手法 → 作者确认位
  L5:全书风格史 + 作者指纹库定稿 → 反哺 style-library

【作者裁决位(仅重大节点)】
  指纹升级 / 风格重定向 / 能力画像 → 展示偏差证据 + 拟处置 → 作者确认后才生效
```

## 边界(自动化程度要守住)

- **采集和检测每章由 write-chapter 定稿后触发**;轻量注入(手法提醒/薄弱项 lessons)持续自动。
- **重量注入分级**:指纹升级、风格重定向、能力画像只在结构节点做,**且保留作者裁决位**。文学上"作者主动的反思"才有效——把作者完全踢出反思环节,会得到"自动化但没有灵魂的进步"。这不是"不够严格",是符合创作规律的必要人工位。
- 与 learn-style 的分工:learn-style 产出**目标指纹**(模仿对象);本引擎维护**实际指纹 + 作者指纹库**(进化)。两者通过双轨对比接缝。
- 与 write-chapter 的分工:write-chapter 的 lessons 飞轮管"每章的写作经验";本引擎管"进化节奏 + 分层学习 + 风格演化"。L1 即时学习留在 write-chapter,L2–L5 归本引擎。

## 喂给谁 / handoff

- **learn-style**:双轨对比的"目标指纹"由它产出;个人化升级回流补进风格库。
- **write-chapter**:L1 即时学留在其 lessons 飞轮;L2–L5 学习决策注入其装配;定向注入替代"最近3条"。
- **remove-ai-tone**:漂移/AI味检测信号接本引擎触发(检测完不再只报错,要触发学习)。
- **plan-plot**:白金手法清单 ↔ 能力画像双向(已掌握/待练)。
- **build-world 面板**:加"进化"区(能力曲线/指纹偏差/手法掌握度)。
- **write-novel**:链路图加横切机制"evolve-style(进化层)";路由表加"该总结了/该学习了"。
- 产物:`<项目目录>/cadence.jsonl` + `evolution/`(作者指纹库/能力画像/进化学报告)。
